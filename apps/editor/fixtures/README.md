# 합성 검수 문서

2026-10-09, 이 편집기의 UI로 작성하고 다운로드 저장한 파일이다. 개인정보나 실제 기관 문서를 포함하지 않는다. 한글 2024에서의 검수는 아직 실행하지 않았다.

| 파일 | 기대 내용 |
| --- | --- |
| three-paragraphs.hwp / .hwpx | 문단 3개: 공무원 문서 편집기 검증 / 한글 2024 기준으로 문서를 작성합니다. / 참석 대상자는 10월 15일까지 신청서를 제출해 주시기 바랍니다. |
| schedule-table.hwp / .hwpx | 업무 추진 일정 + 3×3 표. 구분/담당/기한, 계획 수립/총무팀/10월 15일, 자료 검토/담당 부서/10월 20일 |
| save-and-close.hwp | 저장 후 탭 닫기 검증 |

`tests/document-roundtrip.test.ts`는 기본 본문과 표의 구조·텍스트를 검사하고 HWP/HWPX로 재저장한다. 출력은 같은 엔진의 결과이며 한글 레이아웃 판정은 별도로 한다.
