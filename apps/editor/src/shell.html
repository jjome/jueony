AI 연결 설정

제공자별 연결을 여러 개 저장하고 채팅 위에서 선택할 수 있습니다. 연결 테스트는 문서·대화·자료 없이 합성 요청 1회를 전송하며 API 사용량이 발생할 수 있습니다.

키는 채팅에 저장하지 않습니다. 암호화 저장을 끄면 현재 서버 실행 중에만 유지됩니다. 저장 실패 시 평문으로 저장하지 않습니다. 같은 주소의 모델 변경은 기존 키를 사용하며, 주소·API 방식 변경은 키를 다시 입력해야 합니다.
