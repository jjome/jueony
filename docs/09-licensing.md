# Jueony 이용허락 및 GitHub 적용 기록

2026-10-09 사용자의 지시에 따라 자체 코드·자산에 `Jueony Personal Use License 1.0`을 적용한다. 기준 원문은 루트 [LICENSE.txt](../LICENSE.txt)다. 권리자 표시는 사용자가 지정한 저장소 소유 계정 `jjome`를 사용한다. 법인 명의·실명 등 별도의 권리 귀속은 추정하지 않는다.

- 개인의 사적·비업무용 사용은 무료다. 설치·실행·개인 백업 및 적법하게 받은 원문의 변경 없는 개인 빌드를 허용한다.
- 행정·직무·기업·단체 업무와 상업적 사용은 별도의 사전 서면 허락이 필요하다. 비영리기관, 개인 PC, 재택근무도 업무용이면 무료 허용 범위에 들어가지 않는다.
- 자체 프로그램의 수정·수정본 사용·판매·유무상 재배포에는 별도 허락이 필요하다. 사용자 문서의 편집은 프로그램 수정과 구분한다.
- 제3자 오픈소스 권리와 법정 예외는 우선한다. 기존 MIT 코드를 독점 소유한다고 주장하지 않는다.

이는 프로젝트의 기술적 개발 목표와 일반 이용자에게 부여하는 이용권을 구분한 정책이다. 기관용 개발·공급은 권리자가 별도 허락이나 계약으로 진행할 수 있다.

## GitHub

사용자가 지정한 원격은 `git@github.com:jjome/jueony.git`이다. 연결 전 비공개·빈 저장소이며 기본 브랜치명이 `main`임을 확인했다. GitHub의 Add license 템플릿을 별도로 선택할 필요 없이 원문 파일과 고지를 커밋한다. GitHub의 라이선스 자동 분류 여부가 약관 자체의 효력을 판정하는 것은 아니다.

원격 업로드는 소스와 문서를 대상으로 하며, 무시된 참조 저장소·툴체인·의존성·생성 실행 묶음을 포함하지 않는다. 공개 전환은 이번 작업 범위가 아니다.

## 배포물과 남은 검토

`apps/editor/LICENSE.txt`는 루트 원문의 동일 사본이다. 프런트엔드 빌드는 두 파일의 일치를 검사하고 약관 및 제3자 안내를 `dist`에 복사한다. Rust 실행 묶음 빌드도 약관 및 안내를 실행 파일 옆에 포함한다. 기존 원문 고지는 유지한다.

이번 작업은 라이선스 파일과 고지 연결이며, 설치·최초 실행의 약관 확인/동의 화면이나 라이선스 키·변조 방지 기능을 구현한 것은 아니다. 일반 배포 전에 권리자 식별·문의 경로, 명시적 동의 절차, 실제 구성요소별 고지와 약관의 국내법상 효력을 법률 전문가와 검토한다. 무료 배포라는 이유로 모든 책임을 배제하지 않는다.

약관은 기술적인 복사 방지 장치가 아니며, 법령이나 MIT 등이 허용하는 이용까지 막을 수 없다.
