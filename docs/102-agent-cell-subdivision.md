# 102. 지정 행·열로 셀 분할

2026-10-15. `N005`의 첫 구현은 `split_table_cell_into`다. 기존 병합을 원래 격자로 되돌리는 `split_table_cell`과 별도 명령이다.

## 동작과 경계

조회된 평면 표의 셀 하나를 지정한 행·열로 나눈다. 각 방향은 1~8이며 적어도 한 방향을 나눠야 한다. 분할 후 격자 위치는 200개 이하다. 원래 내용·문단·서식은 첫 셀에 유지하고 새 셀은 비우며 첫 문단 서식을 이어받는다. 비병합 셀 분할 시 이웃 셀은 필요한 만큼 span을 늘린다.

`modules/document/domain/table-subdivision.ts`는 원본 행·열 크기, 안 여백과 최소 크기로 기대 격자를 계산한다. `adapters/rhwp/table-subdivision.ts`는 기존 Native 명령으로 실행하고 실제 격자·본문·자원·표 외곽과 이웃 배치를 검증한다. 공통 snapshot 실행이 요청 단위 undo/redo와 실패 원복을 제공한다. 저장되지 않은 열린 문서가 기준이다.

## 지원과 미지원

- 한 쪽·한 단 HWPX, 보호·제목 셀이 없는 평면 원본, 알려진 크기와 단순 문단을 지원한다. 하나의 병합 주 셀이 있는 표에서는 해당 셀만 분할 대상으로 노출한다.
- 병합 주 셀의 기존 격자 너비·높이를 이웃 셀에서 확인한다. 원래 행·열 수를 지정하면 불균등 격자도 복원한다. 더 적은 수를 지정한 경우 묶음별 너비·높이와 엔진의 분할 결과가 일치해야 한다. 예를 들어 같은 폭·높이의 2×2 격자를 차지하는 셀을 가로 두 줄로 나누면, 표의 전체 격자를 유지하고 각 줄에는 두 열을 차지하는 셀 하나를 둔다.
- 요청당 이 명령 하나를 실행한다. 분할 후 표 외곽을 키우지 않으며 줄바꿈으로 외곽이 커지는 결과도 거절한다.
- HWP, 여러 병합 셀이 있는 원본, 원래 격자선과 어긋나는 병합 셀 분할, 중첩·필드·책갈피·혼합 서식·캡션·복합 배치·여러 쪽 표와 영역 서식은 제외한다.
- 엔진의 `cellZoneCount`가 정확히 0인 경우만 허용한다. 이 관측이 없거나 잘못된 값이면 거절한다. 셀 속성이 같아 보이는 영역 서식도 제외한다.

같은 영역 보호를 기존 기본 분할·병합·표 나누기·붙이기와 행열 구조 변경에도 적용했다. 관측 getter 추가는 영역 서식 편집 자체의 구현이 아니다.

## 검증과 제한

[독립 검사](evidence/table-subdivision-2026-10-15/summary.json)는 단위 7, 실제 Native 14, Edge 13 시나리오를 통과했다. 실제 격자·독립 기대 크기·원본 전체 보존·두 방향 분할·커서·undo/redo·저장·UI 재열기·stale와 render 실패 원복을 포함한다. 네 제공자 호출은 합성 서버다. 최종 빌드의 재검사는 [통합 결과](104-parallel-editor-integration.md)를 따른다.

한글 2024 직접 비교와 실제 계정 호출은 미실행이다. 분할 후 이웃 셀에 span이 생기므로 다음 임의 분할 가능 여부는 다시 조회한다. 모든 병합·중첩 표와 내용 분배 옵션이 구현된 것은 아니며 `N005` 전체는 부분으로 유지한다.

2026-11-08에는 병합 주 셀의 불균등 원래 격자 복원, 같은 치수의 가로·세로 분할, 내용이 밀려 외곽 크기가 달라지는 사례, 오래된 셀 치수와 보호 원본을 실제 WASM으로 검사했다. Edge에서는 로컬 합성 제공자를 통해 2×2 병합 주 셀을 두 줄로 나누고 요청 되돌리기·다시 실행·HWPX 저장·편집기 재열기 후 셀과 글줄 배치를 대조했다.
