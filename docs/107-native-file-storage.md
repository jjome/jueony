# 107. Windows Rust 파일 저장 보호

2026-10-17. [파일·저장·복구](features/05-files-storage-recovery.md)의 기존 B010 저장 보호를 실제 Windows 파일에서도 확인한다. 브라우저 OPFS 검증과 구분한다.

## 수정

Tauri `DocumentFile.read`는 파일을 읽을 때마다 내부 저장 기준 지문을 갱신했다. 따라서 외부 수정이나 다른 프로그램의 신규 파일 생성을 읽은 뒤 쓰면 그 내용을 새 기준으로 받아들여 덮어쓸 수 있었다. 읽기를 `&self`로 바꾸고 기준 지문을 변경하지 않도록 했다. 사용자가 명시적으로 파일을 다시 선택해 새 연결을 만들거나, 실제 저장·재읽기 검증을 마친 경우에만 새 기준을 채택한다.

기존 같은 폴더의 임시 파일 → `sync_all` → 원본 지문 재검사 → 교체 경로는 유지한다. 교체 뒤 실제 파일 바이트까지 확인한 후 기준 지문을 갱신한다. 교체가 끝난 뒤 재읽기에 실패하면 파일이 이미 바뀌었을 수 있으므로 원본 유지나 저장 성공을 주장하지 않는다. 이때 편집기의 dirty·열린 내용은 상위 저장 경로에서 유지된다.

Tauri 명령 계층의 전체 컴파일 검사 중 기본 Windows 아이콘 누락도 발견했다. 외부 이미지·폰트가 없는 자체 문서/J 기하학적 아이콘과 재현 가능한 생성기를 추가했다. 실행 묶음에 쓰는 브라우저 편집 화면의 기능 변경은 아니다.

## 실제 검증

Tauri를 흉내 낸 저장 코드가 아니라 `src-tauri/src/storage.rs` 자체를 경로로 포함하는 작은 테스트 crate를 사용한다. 격리된 Windows 임시 파일과 실제 OS 공유 모드·읽기 전용 속성으로 다음 10개 검사를 수행한다.

| 검사 | 기대 결과 |
| --- | --- |
| 신규/후속 저장과 외부 변경 | 실제 바이트 일치, 외부 수정 덮어쓰기 거절 |
| 다른 프로그램의 파일 선점·빈 데이터·잘못된 확장자 | 원본과 경쟁 파일 보존 |
| 외부 수정 읽기 후 쓰기 | 읽기가 기준을 바꾸지 않으며 쓰기 거절 |
| 신규 파일 선점 읽기 후 쓰기 | 새 파일로 오인해 덮어쓰지 않음 |
| 연결한 원본 삭제 | 자동으로 원본을 다시 만들지 않음 |
| 제한 크기 초과·디렉터리·상대 경로 | 읽기/쓰기 전 거절 |
| Windows 읽기 전용 파일 | 원본·속성 보존, 권한 복원 후 저장 가능 |
| Windows 독점 공유 잠금 | 읽기·쓰기 거절, 잠금 해제 후 회복 |
| 읽기는 허용하되 교체를 금지한 Windows 잠금 | 임시 파일 단계 이후 실패에도 원본 보존·임시 파일 정리, 해제 후 재시도 |
| 실제 엔진 HWP/HWPX | 두 형식의 신규/교체 저장을 바이트 대조, 외부 수정 후 읽기·저장 충돌 보호 |

테스트 crate는 기존 생산 의존성인 sha2/tempfile만 사용하며 잠금 파일과 오프라인 실행을 고정한다. 실제 Tauri 명령 계층의 `cargo check --offline --locked`도 통과했다. 실제 Windows 선택창·전체 Tauri GUI·ACL 모든 조합·디스크 장애·전원 차단까지 검사한 결과는 아니다. 외부 프로그램의 파일 변경을 원자적 compare-and-swap으로 직렬화한다고 보장하지 않는다.

재검사(프로젝트 루트):

```powershell
$env:JUEONY_ENGINE_PACKAGE = 'build/rhwp-engine/source-06b338995d5e1d80/pkg'
node apps/editor/scripts/verify-native-file-storage.mjs
node scripts/generate-native-icon.mjs --check
```

검수기는 자체 HWP/HWPX를 현재 지정 엔진으로 생성·재열기한 뒤 Windows Rust 검사를 실행한다. 실제 검수 시 사용한 엔진과 Rust 소스의 지문은 결과 JSON에 남긴다. 생성된 예제와 결과는 기본적으로 `build/native-file-storage/`에 저장한다. 사용자 문서·열린 서버·한글 창은 사용하지 않는다. 106번의 브라우저 강제 종료 복구 검사와는 별도 경계의 검사다.
