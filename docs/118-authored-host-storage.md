# 앞 문단 재조판 후 HWPX 저장: 합본101

2026-10-18. [파일 작업표](features/05-files-storage-recovery.md) · [이전 합본98](117-file-storage-closure.md) · [고정 검증 근거](evidence/file-completion-2026-10-18/storage101/README.md).

앞 문단을 편집한 뒤 저장·재열기하면 뒤 문단이4px 이동하던 경로를 수정했다. 원본 줄의 좌표계와 다시 조판한 좌표계가 섞일 때, 정확히 소유가 확인된 원본/재조판 쌍으로 간격을 계산한다. 원본 줄 정보·직렬화·저장 보호 비교기를 변경하지 않았다. 이 수정 묶음은 자동 검수를 마쳤고, 파일 파트의 다른 미해결 결함은 계속 남아 있다.

## 이번에 닫은 결함

| 결함 | 수정 | 확인 |
| --- | --- | --- |
| 보이는 표 호스트의 문단 앞 간격 중복 차감 | 원본300HU 간격의 소유를 보존 | 독립 원본과 해당 본문 좌표 차이23→0 |
| 편집 뒤 원본·재조판 축이 섞여 재열기 때 간격 소실 | 소유가 확인된 정확한 역변환만 사용 | 삽입 유지/삽입 후 삭제8경로의 반복 저장·재열기·undo/redo |
| 중간 행의 비정상 높이로 경계 검사 우회 | 모든 행의 끝점을 checked 연산과 원본·역변환 범위로 검사 | 오버플로·중간 돌출 거절, 합법적 중첩 허용 유지 |

새18개 검사는 한글에서 따로 저장해 둔 MCST XML을 열어 실제 편집한 경로다. 원본 HWP는 변경 없는 양형식 저장만 포함한다. 두 입력을 같은 검증으로 혼동하지 않는다.

## 최종 자동 검수

| 검사 | 결과 |
| --- | --- |
| 공식110·같은 프런트101의 파일/복구27군 | 346/346 |
| 새 간격·저장·반례 | 18/18 · 위346에 포함 |
| 단위 | 1008/1008 · skip0 |
| 기존 단·표 저장 | 24/24 · 새 엔진 재실행 |
| 실제 Windows Rust 저장 | 10/10 · ignore0 |
| 실행 묶음 | 7/7 |
| TypeScript·모듈 경계·작업표12개 | 통과 |

실제 입력 글자·디스크 바이트·전체 의미·공개 지면을 검사한다. 저장 차단은 성공으로 세지 않는다. 좌표 허용오차0.2와 원본/보호 코드 지문을 유지했다. 첫 검사기가 다른 문서 인스턴스에 snapshot ID를 사용한 오류는 실패 근거로 남겼고, 최종 검사에서는 원래 인스턴스를 유지했다.

## 이어서 해결할 잔여

| 잔여 | 현재 확인한 상태 | 다음 작업 |
| --- | --- | --- |
| 원본 MCST HWP 편집 후 HWPX 저장 | 기존107/109에서 의미0·지면5232 차이로 실제 저장 보호가 거절 | 편집하지 않은 앞쪽 표에 전역 편집 상태가 적용되는 원점 경계 수정 중 |
| Python 복합 프레임 | 별도 후보에서 잘못된 표 기준점까지 좁힘 | 다른 표의 원본 행을 빌려 쓰는 오류와 바깥 아래 여백 소유 수정·회귀 |
| 최초 원본 조판 | MCST15쪽/한글 재저장 XML16쪽, 글줄·글꼴 차이 | 실제 자료와 소유 근거별로 분리 검증 |
| 명시 글 방향의 HWP5 저장 | 확인된 표준 매핑 부족 | 예약 비트 추측 없이 근거 확보, 손실 변환 차단 유지 |
| HWT 본문 쓰기·일반 XSD/XSL | 읽기/제한 XSD까지만 제공 | 모호하지 않은 필드와 같은 HWT 컨테이너 보존부터 별도 검사 |
| 실제 한글·OS 화면 | 사용자 지시에 따라 보류 | 마지막 일괄 직접 비교 |

기존 작업표의24개 실행 작업과10개 상위 요구는 유지한다. N001은 위 잔여 때문에 부분이며, 상위0/10을 완료로 올리지 않았다. 이번에 닫은 세 결함과 합본 검사 결과를 함께 읽는다.

## 실행

`Start-Jueony-FileReview.cmd`는 별도 `build/jueony-file-review101/Start-Jueony.cmd`를 연다. 기존 사용자 실행본과 문서는 종료하지 않았다. 새 실행 묶음의 기본 주소는 `127.0.0.1:4366`이다.

공식 빌드: `scripts/Build-DocumentEngine.ps1 -Runtime Wsl`. 해당 pkg와 `JUEONY_BUILD_PROFILE=file-storage101`을 지정해 프런트를 빌드한다. 합본 검수기는 기본 입력 외에 원본 셀용 baseline/source/oracle와 새 간격용 floating-host-baseline/source/oracle를 각각 모두 요구한다. 입력 누락은 통과나 건너뜀으로 세지 않는다.
