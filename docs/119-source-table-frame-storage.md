# 표 기준점·바깥 여백 저장: 합본104

2026-10-18. [파일 작업표](features/05-files-storage-recovery.md) · [직전 합본101](118-authored-host-storage.md) · [고정 검증 근거](evidence/file-completion-2026-10-18/storage104/README.md).

Python 예제에서 다른 표의 원본 행을 빌려 쓰던 기준점과 아래 여백 누락을 수정했다. 공식111·같은 프런트104의 파일/복구351개가 통과했다. **원본 MCST의 편집 저장은 별도 미해결이며 파트 전체 완료가 아니다.**

| 이번에 닫은 결함 | 수정 | 근거 |
| --- | --- | --- |
| 단 첫 표가 다른 TAC 표의 원본 행을 차용 | 실제 control index·전체 물리 상자와 행 소유를 확인 | 부유 sibling은 기준점 권한을 얻지 않음 |
| 단 위의 빈 RowBreak 표 아래 여백 미소비 | 실제 column-top·높이·별도 TAC 행·양수 바깥 여백을 확인 | 세 표 원점이 독립 한글 저장본과0.2 이내 일치 |
| 새 소유 경계의 잘못된 확대 | 행 끝 checked 연산, 음수 여백 거절, page-band/본문 재귀 문맥 구분 | 선택 Rust6개 통과, 과도 깊이·노드·notes·unknown은 기존 경로 유지 |

기존 native 빈 표 경로와 글꼴 폭을 바꾸지 않았다. Header/Footer의 표는 별도 page-band 문맥으로만 검사한다. 본문 중첩 개체나 미확인 제어에 같은 권한을 주지 않는다.
