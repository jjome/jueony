## 수정한 원인

불균등 단의 빈 줄은 실제 allocator가 높이를 소비했지만, 오래된 합성 행 너비가 현재 단 너비와 달라 paint가 줄 전체와 높이를 생략했다. 현재 빈 formatter·확정 FullParagraph·원문 소유·실제 프레임이 모두 일치할 때만 별도 FullEmpty 경로를 사용한다. 기존 너비 거절 조건과 전체 trace 예산, 기존 원본·캐시·저장 권한은 유지한다. 일반2·3단의 단순 본문과 inline 표 범위에 한정하며 독립적으로 위치하는 float 표는 기존 경로를 유지한다. 초기 후보가 오프셋 문서를 새로 거절하던 회귀는 최종r4에서 해결한 뒤 통합했다.

표 호스트에는 실제 표와 뒤 본문의 fresh 조판·확정 배치·물리 프레임을 함께 검증하는 별도 HWPX 경로를 추가했다. 문단 모형·원본 행·serializer의 기존 보호를 바꾸지 않는다. 이 단계는 XML 동형식만 닫았으며, Native와 형식을 오가는 경로는 다음 원점 처리로 계속 수정 중이다.
