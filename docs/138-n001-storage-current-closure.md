## 실제 수정 내용

저장 시각 복사본에는 원본에서 검증한 행의 소유와 정확한 복사본 메타데이터를 함께 묶는다. 본문 분할은 실제 formatter의 행 번호와 저장용 행 번호를 구분하고, 단 맨 위가 아닌 문단의 시작 위치도 보존한다. 쪽/종이 기준 표는 현재 실제 행 높이와 공간을 사용한다. 빈 본문의 사용되지 않는 폭은 글자·저장 행 권한으로 바꾸지 않는다.

2열 병합 표는 실제 행 최대 높이를 예약해 초기3쪽을 올바른4쪽으로 바꾼다. 세로 병합의 마지막 잘린 띠는 정확한 내용 경계로 닫아 중복8개 run을 없앤다. 이 수정은 초기 표시의 bbox 일부를 바꾸지만 세로 병합 원본의 HWP/HWPX export 바이트는 그대로다. 기존 표시가 모두 정확했다는 주장은 하지 않는다.
