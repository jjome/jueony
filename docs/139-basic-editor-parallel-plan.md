각 묶음은 현 코드에서 재현한 문제와 확인 가능한 완료 조건을 먼저 고정한다. 실제 한글 2024 직접 비교는 사용자의 앞선 지시에 따라 마지막 일괄 검수로 남긴다. 자동 검사만 통과한 항목을 한글과 완전히 동일하다고 표시하지 않는다. 지원하지 않는 복합 문서 변경을 성공으로 보고하거나 저장 보호 검사를 완화하지 않는다.

결과와 다음 작업은 이 문서에 같은 작업 묶음 단위로 덧붙인다. 기능별 표의 기존 상위 범위를 완료로 바꾸려면 그 범위 전체의 근거가 필요하며, 이번의 좁은 수정은 별도 실행 항목으로 기록한다.

## 집계 누락 보정 · N046

사용자의 “부분 완료를 완료로 표시하지 말라”는 지시에 따라 기존 설명에만 남아 있던 문단 `textDir` 변환을 별도 N046 실행 작업으로 등록했다. 새로 발생한 회귀나 N001 재개방이 아니다. 원래부터 HWPX 정확 보존과 HWP 저장 차단만 구현됐고 HWP5 매핑은 남아 있었다. Rust182/183의 동일 공개 문서 실패 근거도 확인했다. 따라서 파일 영역은 **구현24/25·부분1, 검증22/25·부분3, 전체 범위0/10**이다. 과거 시점의 증거 문서 숫자는 유지하되 현재 진행표는 이 잔여를 분모에서 빠뜨리지 않는다.
