작업 기준 시각은 한국 시각 2026-10-24 새벽 2시다. 사용량 초기화가 이 시각에 일어난다는 가정 없이 작업한다. 본문 편집, 기본 키, 상태 복원 순으로 일상적인 편집 동작을 우선한다. 담당자는 파일 소유 범위를 분리하고 공통 빌드·명령 연결과 문서 집계는 통합 담당이 처리한다.

기준 커밋은 `f765f352`이며 기존 파일·저장·복구·형식 보존의 구현 24/24와 Rust182 엔진을 유지한다. 기존 미커밋 변경은 별도 작업이므로 포함하거나 덮어쓰지 않는다. 통합 검수는 HEAD 기준 사본에 이번 변경만 반영하여 수행한다.

각 묶음은 현 코드에서 재현한 문제와 확인 가능한 완료 조건을 먼저 고정한다. 실제 한글 2024 직접 비교는 사용자의 앞선 지시에 따라 마지막 일괄 검수로 남긴다. 자동 검사만 통과한 항목을 한글과 완전히 동일하다고 표시하지 않는다. 지원하지 않는 복합 문서 변경을 성공으로 보고하거나 저장 보호 검사를 완화하지 않는다.

결과와 다음 작업은 이 문서에 같은 작업 묶음 단위로 덧붙인다. 기능별 표의 기존 상위 범위를 완료로 바꾸려면 그 범위 전체의 근거가 필요하며, 이번의 좁은 수정은 별도 실행 항목으로 기록한다.

동시에 진행하는 다음 묶음은 단축키 확대, 리본·스타일 창 및 최근 글꼴 저장, 개체 잘라내기 실패 보호다. 새 글꼴의 HWPX 저장 차단과 언어별 글꼴 참조 오류를 발견하여 별도 Rust/명령 수정·회귀를 진행한다. 이 미검증 변경은 1차 완료에 포함하지 않는다.

진행표 표시: 각 열이 N/N인 경우에만 로컬 초록색 배지를 사용한다. 구현이 완료되어도 검증이 부분이면 검증 숫자는 별도로 유지한다. 상태 집계 자체를 색상에 맞춰 올리지 않는다.

근거: [2차 검증 묶음 및 SHA256](evidence/basic-editor-2026-10-24/second/manifest.json). 실제 엔진은 Rust183이며 새 글꼴 선언에만 TTF 종류를 설정한다. 가져온 글꼴의 미지원 종류나 저장 보호 검사를 완화하지 않는다. 단위 1,118개, TypeScript 및 모듈 경계 검사는 통과했다. 본문 모양 복사 8개 재검사도 통과했다. 자동 검사만으로 한글 2024 동일 동작을 완료 처리하지 않는다.

추가 회귀에서는 기존 공개 문서의 HWPX→HWP 변환이 `paragraphProperties/textDir` 메타데이터 188개 손실 보고로 차단되는 사례를 확인했다. 동일 파일을 기존 Rust182로 다시 검사해 같은 실패를 확인했다. 글꼴·16쪽 배치 비교는 같지만 저장 보호 통과로 기록할 수 없다. 해당 반례는 [별도 실패 근거](evidence/basic-editor-2026-10-24/second/existing-conversion-limitation/verify-font-fallback-storage-engine.json)에 남긴다. 이 변환 범위를 포함한 파일 기능 전체가 완료됐다는 뜻이 아니다.

진행표는 숫자 열을 가운데 정렬하고 `전체 범위 완료 / 세부 구현 / 세부 검증 / Agent 연결`을 구분한다. 초록색 N/N은 해당 열의 기록된 세부 작업만 뜻하며, 부분 항목을 완료 수에 넣지 않는다. 파일 기능의 검증22/24·부분2와 전체 범위0/10은 유지한다.
