# AI 대화·문서 너비 조절과 실제 Agent 검사

2026-10-11. AI 대화 영역과 문서 영역 사이의 세로 분할선을 추가했다. 문서의 용지 설정을 변경하는 기능이 아니라 화면 공간을 나누는 기능이다.

## 사용 방법

- 분할선을 좌우로 드래그한다. 문서 iframe 위로 이동해도 드래그를 유지한다.
- 분할선에 포커스를 둔 뒤 좌우 방향키로 10px, Shift와 함께 40px씩 조절한다.
- Home/End는 허용되는 최소/최대 너비로 이동한다.
- 두 번 클릭하거나 Enter를 누르면 기본 너비로 복원한다. 드래그 도중 Escape는 취소한다.
- 너비를 로컬 업무 저장소에 저장한다. 같은 브라우저 프로필에서 다시 열면 복원된다. 창이 작아질 때는 두 영역을 화면에 맞추고, 다시 커지면 사용자가 정한 너비로 돌아간다.

이전 저장소의 `agentWidth`가 없어도 기본값으로 열린다. 문서 내용·용지 속성·revision은 크기 조절로 변경하지 않는다. 새 화면은 실행 묶음에 반영했으며, 기존 창은 열린 문서를 저장한 뒤 새로고침한다. 이번 UI 변경에는 서버 재시작이 필요하지 않다.

## Agent 연결 확인

첫 검사 당시 실제 `4173` 서버는 `documentControlVersion: 1`이었지만 등록된 모델 연결 목록이 비어 있었다. 모델 버전 지원과 실제 인증 연결은 별개다. Windows 암호화 저장소에는 기존 HCX-005 연결이 남아 있어, 키를 출력하거나 소스에 넣지 않고 현재 서버에 다시 등록했다. 서버의 연결이 비어 있었던 경위는 이 검사만으로 확정하지 않았다.

그 뒤 **현재 실행 중인 `http://127.0.0.1:4173/` 서버**에 별도 임시 Edge 프로필로 접속했다. 사용자 workspace나 열려 있는 원본 문서에는 입력하지 않았다. 합성 문서를 열고 채팅 입력창에 다음 요청을 실제 입력한 뒤 ‘요청 보내기’를 눌렀다.

> 제목 ‘업무 계획’을 16pt 굵게로 바꾸고, ‘추진 일정’ 뒤에 4행 3열 표를 만들어줘. 내용은 [단계, 기간, 담당], [준비, 1월, 총무], [실행, 2월, 사업], [점검, 3월, 감사]야. 첫 행만 굵게 하고 회색 배경을 적용해줘. A4 가로와 좌우상하 여백 20mm로 바꾸고 본문 텍스트는 유지해줘.

실제 HCX-005 API 호출 1회에서 공통 편집 명령 4개가 반환되었고 문서에 적용되었다. 모든 셀의 내용, 첫 행만 굵게/회색인지, 제목 크기·굵기와 용지 방향·여백을 검사했다. 이어 변경 확인을 열고 요청 되돌리기로 원래 구조와 서식을 복원했다. Agent가 메시지만 생성한 상태가 아니라 현재 편집 엔진까지 연결되어 동작하는 것을 확인했다.

실행 방식은 기존과 같은 **문맥 구성 → 모델 호출 1회 → 명령 검증 → 열린 문서 적용**이다. 자율 반복 Agent나 외부 MCP 서버가 추가된 것은 아니다. 모델의 다른 요청 정확도와 실제 한글의 파일 호환성을 보증하는 검사는 아니다.
