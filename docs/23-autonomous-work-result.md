## 검사 결과

앱/엔진 42개와 로컬 API/제공자 37개가 통과했다. 브라우저에서는 새 제공자/첨부 9, 기존 업무 흐름 19, CLOVA fixture 업무 흐름 20, 연결 키 관리 6, 단축키 9, 구조 편집 7개 시나리오를 통과했다. 검사 수는 서로 다른 검사 묶음이므로 전체 기능 개수로 해석하지 않는다.

마지막 실행 묶음에서 기존 HCX-005 서비스 키로 합성 요청을 **실제 2회** 호출했다. 안내문 생성, 제목 교체/굵기/크기 변경, 다른 문단 보존, undo, 진행 표시를 확인했다. 사용자 실제 업무 자료와 공개 표본은 전송하지 않았다.

GPT·Claude·Gemini는 native HTTP fixture→UI→엔진 연결을 검증했지만 실제 계정 키가 없어 실호출하지 않았다. 사용자가 각 키와 지원 모델 ID를 등록하면 합성 연결 테스트와 문서 작성을 이어갈 수 있다.

공개 표본 5개 모두 열렸고 10개 저장 파일 모두 재열렸다. 4개는 추출 내용·표 비교 통과, 1개는 HWP 변환 뒤 끝 빈 문단 증가로 검수 판정이다. 실제 한글 2024의 시각·인쇄 검수는 아직 하지 않았다. 자세한 기록은 [검증 증거](evidence/native-agent-2026-10-11/README.md)에 있다.

## 남은 범위

**한글의 모든 기능과 모든 문서 호환성을 완성한 상태는 아니다.** 전체 목록은 [기능별 작업표](ai-editor-capability-matrix.csv)에 유지했다.

| 남은 항목 | 현재 상태와 다음 작업 |
|---|---|
| 실제 3 제공자 계정 | 키·모델 권한 등록 후 실호출, 구조화 출력 지원과 품질 평가 |
| 표 고급 기능 | 병합/분할·중첩·테두리·크기/배치·계산 등 engine/저장/undo 검증 후 명령 추가 |
| 본문·스타일 | 혼합 서식 보존, 문단 이동, 스타일 CRUD·목록·탭·부분 선택 확대 |
| 개체·필드·고급 쪽 | 그림/도형/글상자/수식 편집, 머리말/꼬리말·필드·주석·구역 등 별도 검증 |
| 저장·복구 | 자동 저장 도구, 재시작 후 요청 undo, 강제 종료/부분 쓰기 복구 보강 |
| RAG·loop | [설계](22-agent-retrieval-execution-design.md) 완료, 런타임은 현재 single 유지 |
| 외부 MCP | 내부 편집 도구와 열린 session을 공개할 adapter 설계, 아직 서버 미구현 |
| 독립 호환성·기관 배포 | 실제 한글 검수, OS 오프라인 검사, endpoint 정책·보관 정책·배포 구성 확인 |

기능명이 엔진에 존재한다는 사실만으로 자동 편집 지원으로 노출하지 않았다. 대상 검증·적용·실패 복원·undo·두 형식 저장을 통과한 범위를 먼저 연결했다. 미지원 항목은 실행 성공으로 응답하지 않는다.
