# 한글 편집기 구현 상태와 남은 작업

2026-10-13 기준. Jueony HEAD `dd79d2f`의 소스·생성된 Studio 코드·추적 엔진 패치와 [188행 기능 점검표](hangul-2024-gap-checklist.csv)를 대조한 당시 감사 기록이다. 아래 진척 수치는 그 시점 기준으로 유지한다. 이후 점검표의 쪽 복사/붙이기 B185/B186은 [55번 후속 구현](55-page-body-copy-and-paste.md)의 제한된 본문 범위 검사로 PARTIAL에 갱신했다. 최신 구현으로 한글 GUI 전수 동등성이 입증된 것은 아니다.

## 진행률

**점검표 기준 관리용 구현 진척은 약 49%다.** 아래 계산은 모든 행의 가중치를 같게 두고 부분 구현을 임의로 50%로 환산한 추정 지표다. 코드 작성량, 남은 개발 시간, 실제 한글의 전체 기능 수 또는 호환성 완료율이 아니다.

| 분류 | 항목 수 | 의미 |
| --- | ---: | --- |
| WIRED | 66 | 기본 실행 경로가 연결됨. 전체 옵션·문맥·한글 동등성 완료를 뜻하지 않음 |
| PARTIAL | 51 | 일부 옵션·대상만 지원하거나 동등성 확인이 남음 |
| MISSING | 68 | 대응하는 제품 기능의 생성·편집 경로가 없음 |
| STUB | 3 | 등록만 되어 있거나 비활성 상태. 메모 두 행은 같은 기능군 중복 |
| 합계 | 188 | 독립된 한글 전체 기능의 개수가 아니라 현재 관리 점검표 행 수 |

계산: `(66 × 1 + 51 × 0.5) ÷ 188 × 100 = 48.7%`.

실행 경로가 연결된 행의 비율은 **35.1%**, 일부라도 구현된 행의 비율은 **62.2%**다. 남은 보강 항목은 부분 구현 51행과 미구현·비활성 71행, 합계 **122행**이다. 이 외에도 WIRED 66행의 상세 옵션·복합 문서·실제 한글 대조 검수가 남는다. B092/B136의 메모 중복 행을 하나로 세면 187행 기준 추정은 48.9%이며, 동일하게 약 49%다.

부분 구현의 실제 규모를 아직 세부 옵션별로 측정하지 않았다. 환산 가중치를 25~75%로 바꾸면 추정치는 41.9~55.5%다. 따라서 48.7%를 정밀하게 측정한 제품 완성률로 사용하지 않는다. 외부 서비스·특수 출력 형식을 제품 범위에서 제외하려면 먼저 분모를 명시적으로 다시 정의해야 한다.

## 현재 작동하는 중심 기능

HWP/HWPX 열기·저장, 본문 입력과 기본 글자·문단 서식, 찾아 바꾸기, 되돌리기·다시 실행, 단순 표 생성과 셀 편집·행열 변경, 기본 개체 삽입과 속성 변경, 쪽·구역·기본 탭 설정이 연결되어 있다. 스타일 관리, 제한된 문서 끼워 넣기, 문자열과 표 변환, 정수 자동 채우기, 문서 탭 단축키도 보강했다.

업무·채팅·폴더 연결과 문서 복구, 배율·스크롤, 본문·셀·중첩 셀·일부 개체·머리말·각주의 커서와 선택 복원도 구현되어 있다. 지원 범위와 제한은 [통합 검수 결과](44-editor-stages-result.md)를 따른다.

직전 통합 검수 기록은 단위 351개, 브라우저 133개, native WASM·독립 XML 58개 통과다. 테스트 사례 수는 기능 항목의 완료 수가 아니다. 현재 기능표에 행별 검증 이력을 기록한 것은 23/188행이며 165행은 `NOT_RUN`이다. 이는 시험 증거 연결의 상태이며, 실제 자동 검사 전체의 커버리지로 환산할 수 없다. 한글 전체 동작·지면 동등성의 완료율은 아직 산정할 수 없다.

## AI와 RAG는 별도 집계

위 49%에는 workspace·LLM·RAG·Agent 구현을 더하지 않는다. 현재 AI 편집 계약은 본문 4종과 구조/서식 13종, 합계 17종이다. 수동 편집기에 연결된 모든 기능을 AI가 호출할 수 있는 상태는 아니다. 표 병합·중첩, 개체·주석, 구조 이동, 고급 쪽 설정과 저장 등의 공통 도구 연결은 별도 Agent 작업이다.

RAG 예제 21개와 질문 22개를 준비했고, 자료·문맥·출처·범위 검사 69개는 통과했다. 검색의 첫 정답 문서 비율은 27.8%이며 답 없는 질문에도 검색 결과가 반환되는 문제가 있다. 이것을 한글 기능의 진행률이나 실제 모델 답변 성능으로 합산하지 않는다. [RAG 기준선](45-rag-evaluation-corpus.md)을 따른다.
