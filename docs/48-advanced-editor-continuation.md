# 표·기본 편집 잔여 기능 연속 구현

2026-10-13. 실제 한글 비교는 나중에 일괄 수행한다. 이전 [실행 묶음](47-remaining-editor-implementation.md)은 유지하고, 새 구현은 별도 빌드로 검사한다. 작업 단위가 끝났다고 전체 한글 기능 구현을 완료한 것으로 표시하지 않는다.

## 구현한 기능

| 기능 | 적용 범위 | 남은 제한 |
| --- | --- | --- |
| 혼합 서식 문자열↔표 | 본문 전체 문단과 단순 표의 글자별 서식을 scalar 좌표로 나누고 복원. 이모지·빈 셀·행 스타일 유지 | 평면 비병합·보호 없는 단일 문단 셀. 필드·개체·여러 쪽·다단 제외. 새 구분자는 앞 셀 마지막 글자/입력 서식을 사용하므로 원래 구분자 전용 서식까지 복원하지 않음 |
| 기본 표 모양 | 본문 표 개체 선택 → 표 메뉴 → 기본 표 모양. 격자·파란 제목행·회색 줄무늬·테두리/배경 없음. 제목행 색 선택, 미리보기·취소·한 번 undo | 자체 제작 모양이며 한글 원본 갤러리 아님. 전체 표만 적용. 세로 병합·보호 셀·중첩 표 제외. 셀 글자·문단·크기·여백·대각선은 유지 |
| 본문 문단 정렬 | 편집 메뉴. 한국어 자연 문자순 또는 정확한 부호 있는 소수순. 문단 전체/탭 열 기준, 첫 문단 유지, 오름·내림차순. 동률 원래 순서 유지. 내용과 혼합 서식·문단 모양·스타일을 함께 이동 | 같은 쪽·단일 단 본문 전체 문단 2~1,000개. 자동 번호·필드·개체·표·특수 영역·쪽 경계 제외. 한국어 정렬 규칙과 한글 2024의 동등성 미판정 |
| 셀 저장 보호 | 저장 전후 셀 테두리·배경·대각선·크기·여백·보호·배치 속성을 글자 run과 함께 검사 | 같은 엔진 재열기 검사. 실제 한글 조판 검증, 해석하지 못하는 payload 검증을 대체하지 않음 |
| 병합 표 뒤집기 | 표 개체 선택 후 T. 가로·세로 병합 footprint, 여러 문단, 혼합 서식과 영역 배경을 이동. 새 Rust 패치에서 전체 격자 검증 후 전치, 한 번 undo | 본문 전체 표 1,000셀 이하. 보호·반복 제목행·중첩 대상 제외. 테두리를 도형처럼 회전하지 않음. 너비 재배분/행 높이 정책과 실제 한글 동등성 별도 |
| 월·년 날짜 채우기 | 자동 채우기 창에서 일/월/년 간격을 명시적으로 선택. 첫 날짜의 일을 기준으로 없는 날만 그달 말일로 조정. 역방향·윤년 지원 | 날짜 추론·월말 여부 자동 추론·요일 간격 제외. 두 번째 날짜가 선택한 정책과 맞지 않으면 거절. 정수/번호에 월·년 선택 불가 |

각 변경은 열린 문서의 명령/snapshot 경로를 이용한다. 대화상자 확인 시 문서 버전과 선택을 검사하고, 사본에서 편집·저장·다시 열기를 통과한 뒤 적용한다. 저장 보호를 해제하여 통과시키지 않는다. 실패는 snapshot router가 복구한다.

## 검증

`docs/evidence/advanced-editor-2026-10-13/`에 단위 결과, 별도 브라우저 결과와 합성 문서를 저장한다. 최초 묶음은 단위 382개, 실제 Edge 표·정렬 화면 10개, 생산용 WASM 9개 검사를 통과했다. HWP/HWPX의 scratch 검사·실제 저장·다시 열기·undo/redo를 포함한다. 실제 한글과 유료 모델은 호출하지 않았다.

표 갤러리 검사에서 HWPX가 표현하지 않는 대각선 비트 조합 `1`이 `ALL(7)`로 변환됨을 확인했다. 검수 문서는 두 형식에서 표현 가능한 `7`을 사용한다. 새 셀 속성 저장 보호는 이런 차이를 조용히 허용하지 않는다. 원본 복잡 문서는 추가 차이가 발견되면 저장을 차단할 수 있다.

## 후속 검증과 실행

병합 표 뒤집기는 추적 Rust 패치에서 새 WASM으로 빌드하여 검사한다. 표 모양의 두 번째 셀 적용 실패, 정렬의 첫 텍스트 교체 후 서식 적용 실패를 주입하여 내용·서식·이전 undo 기록 복원을 확인한다. 명령 등록뿐 아니라 실제 통합 메뉴 노출과 신뢰된 키보드 T 입력도 검사한다.

검수 실행기는 `build/jueony-advanced-editor-20261013/Start-Review.cmd`, 포트 4221이다. 이미 사용 중인 4220 실행본은 자동 종료하지 않는다. 새 포트의 업무 저장소는 별도로 보이므로 기존 문서를 파일에서 다시 열 수 있다. 합성 검수 파일은 실행 묶음의 `review-documents/advanced-editor/native/`와 `browser/`에 포함한다.

최종 검사 수치와 모든 소스·빌드·엔진 해시 일치는 증거 폴더의 `verification-summary.json`을 따른다. TypeScript와 모듈 경계, 실제 Edge 브라우저, 합성 Agent, 실행 묶음의 이전 데이터 호환을 검사한다. 복잡한 개체·검토·보안·기관 통합 등 전체 잔여 목록은 [기능 점검표](hangul-2024-gap-checklist.csv)에 유지한다. 새 수동 명령을 Agent 지원 계약에 추가한 것으로 표시하지 않는다.

최종 소스에서 단위 **383개**, 실제 Edge 브라우저 **132개**, 생산용 WASM **15개**를 통과했다. 브라우저 수치는 표·정렬·월/년·병합·실패 복원 16개, 기존 편집 66개, 상태 복원 9개, 기본 글자/양식/상용구 28개, 합성 Agent 9개, 실행 묶음 호환 4개다. 모듈 경계는 9개 모듈·215개 소스, TypeScript 오류는 0이다. 각 결과의 소스·빌드·WASM·표 연결 패치 해시 일치를 `verify-advanced-evidence.mjs --include-bundle`로 확인했다. 실패·skip·외부 자산 요청은 0이다.
