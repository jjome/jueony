# 완전한 본문 문단의 쪽 복사·붙이기

2026-10-14. [54번 쪽 지우기](54-complete-body-page-deletion.md) 후속이다. 한글 직접 비교는 마지막 일괄 검수로 남긴다.

## 사용자 동작과 범위

쪽 메뉴의 **쪽 본문 복사 (완전 문단)**로 현재 쪽을 확인하고 복사한다. **쪽 뒤에 본문 붙이기**는 커서가 있는 쪽의 바로 뒤에 새 쪽으로 넣는다. 문단별 글자·문단 서식과 스타일 참조를 실제 엔진 모델로 옮긴다. 일반 텍스트나 HTML로 축소하지 않는다.

- HWP/HWPX의 가로쓰기·한 단 일반 본문에서 한 쪽에 완전히 들어가는 연속 문단을 대상으로 한다. 1,000문단·10만 문자·32MiB 이하이며 한 구역·한 쪽 사본만 붙인다.
- 여러 쪽에 걸친 문단, 표·개체·필드, 다단·세로쓰기, 바탕쪽·줄 번호·그림 배경·사용자 단 너비·개요 번호 본문·미지원 구역 설정은 제외한다.
- 같은 용지·쪽 설정에 붙인다. 다른 설정의 쪽을 위한 새 구역 생성은 아직 구현하지 않았다. 서로 다른 설정을 조용히 대상 설정으로 바꾸지 않는다.
- 복사 버퍼는 프로그램 내부 메모리다. 다른 열린 문서 탭에서 명시적으로 붙일 수 있으며 원본을 이후 수정해도 복사 시점 내용을 유지한다. 재실행 후 복원이나 Windows/한글 클립보드 연동은 아직 지원하지 않는다.
- 복사는 문서 dirty/undo를 만들지 않는다. 붙인 전체는 한 번의 undo/redo로 복원하고, 일반 안전 저장을 사용한다. 취소·오래된 대상·적용 실패에서 원문과 기존 undo를 유지한다.

[한글 2024 쪽 복사](https://help.hancom.com/hoffice130/ko-KR/Hwp/format/copy_page.htm)의 현재 쪽 복사·선택 쪽 뒤 붙이기를 출발점으로 삼았다. 한글의 개체·다른 용지 구역 처리나 OS 클립보드와 동일하다고 판정하지 않는다.

## 구현 경계

`zzzz-page-body-copy.patch`는 기존 완전 문단 범위 검사와 구역 정의 재연결을 공유한다. 복사 사본에 선택한 구역/문단만 남기고 원본 미리보기·보조 ZIP 엔트리·추가 CFB 스트림·전역 문서 설정을 제거한다. 글꼴·글자/문단 모양·스타일 등 자원 풀은 참조 유지와 외부 문서 삽입을 위해 함께 옮긴다. 선택 문단만의 최소 자원 풀을 만들거나 비식별화를 제공하는 기능은 아니다.

HWP 계보의 문자/조판 축은 기존 HWPX export 경로를 사용한다. 복사 사본을 다시 열어 한 쪽과 같은 본문 범위인지 검사한다. 붙이기는 기존 외부 문서 자원 이식/ID 재연결을 사용하며, 앞·뒤 쪽 경계를 연결한 뒤 본문·문단 수·쪽 수를 다시 확인한다. 결과가 어긋나면 원문 모델을 복원한다.

설정 비교는 자원 ID나 HWP 테두리 저장용 예약 비트로 판단하지 않는다. 실제 테두리·배경 색·간격·쪽 종류·표시 범위와 용지/구역/단 설정을 비교한다. 무늬 없음의 HWP `0`과 HWPX `-1`은 기존 서식 계약에 맞춰 같은 값으로 본다. 대상 문서의 예약 비트를 수정하거나 일반 저장의 원본 보호 검사를 완화하지 않는다. 원본과 붙인 글자 속성도 이식 후 바뀔 수 있는 모양/자원 ID를 제외하고 실제 속성으로 검사한다.

앱은 `modules/document/domain/page-body-clipboard.ts` 계약과 `adapters/rhwp/page-body-clipboard.ts` 명령을 사용한다. 버퍼를 읽을 때마다 사본을 만들며 iframe 사이의 typed array도 검사한다. 버퍼는 자동으로 다른 workspace 자료나 Agent 문맥에 들어가지 않는다.

문서 revision·커서·본문 범위·구역 token을 확인하고, 저장 사본에 붙여 저장/재열기 보호 검사를 먼저 수행한다. 실문서는 Studio snapshot 명령으로만 바꾼다. 구역 token은 전체 문서 revision의 대체물이 아니다.

## 검증 진행

전용 엔진 검사 16개, 실제 Edge 검사 11개가 통과했다. HWP/HWPX의 첫/중간/마지막 쪽을 각각 복사해 각 쪽 뒤에 붙인 순서·쪽 수·용지·저장 재열기, 여러 본문 문단과 혼합 글자 서식, 다른 문서 탭 사용과 복사 시점 유지, 구역 경계, 취소·오래된 원문·잘못된 미리보기, 다른 용지/배경 색·걸친 문단·표 거절 및 실문서 적용 후 실패 복원을 검사했다. 추가 ZIP/XML 검사는 합성 원본의 전체 미리보기·별도 메타데이터 표식을 사본에서 제거했는지 확인한다.

최종 자동 회귀는 단위 404개, 브라우저 235개, 엔진 151개가 통과했다. TypeScript와 9개 모듈/226개 소스 경계 검사도 통과했다. [검증 요약](evidence/page-copy-2026-10-14/verification-summary.json)은 모든 보고서의 소스·통합 패치·WASM 해시를 대조한다. Agent는 로컬 mock을 사용하며 실제 유료 모델이나 한글 지면 동등성 검사로 계산하지 않는다.

검수 중 원래 단 정의가 없는 사본과 HWP/HWPX 저장 표현 차이를 수정했다. 머리말 회귀의 동시 검사에서는 취소 직후 다시 연 대화상자의 ID로 옛 hidden 버튼을 잡아 detached 오류가 발생했다. 단독 검사에서 동작을 확인하고, native dialog의 close listener가 DOM 제거를 완료한 후 다시 열도록 검사를 보강하여 66개 편집 회귀가 통과했다. 제품 보호 조건이나 시간 제한은 바꾸지 않았다.
