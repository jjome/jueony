# Agent의 기본 단색 쪽 배경 명령

2026-10-14. 수동 쪽 배경 편집에 이어 현재 열린 문서의 기본 배경을 내부 Agent 명령으로 연결한다. 문서 상태의 소유자는 기존 rhwp 엔진이며 Python이나 별도 디스크 편집은 사용하지 않는다. 한글 2024 직접 비교는 마지막 일괄 검수로 남긴다.

## 지원 범위와 계약

`set_page_background`는 기존 구역의 배경 없음 또는 무늬 없는 단색을 변경한다. HWP/HWPX를 지원한다. `pageKind`는 `both`, `even`, `odd`이며 `both`는 기존 양쪽·짝수·홀수 배경에 같은 채움을 적용하되 각 항목의 테두리·기준·간격·머리말/꼬리말 포함·배치 영역을 유지한다. 홀수/짝수 명령은 반대 쪽 배경을 바꾸지 않는다. 기존 첫 쪽 표시·감추기 설정도 유지하므로 모든 쪽에 표시된다고 응답하지 않는다.

```json
{"kind":"set_page_background","section":0,"pageKind":"both","fillType":"solid","color":"#fff2cc"}
```

배경을 지울 때는 `fillType:"none"`, 필수 색 값은 `color:"#ffffff"`로 보낸다. 이 색 값은 배경 없음일 때 그리지 않는다. 새 구역을 만들거나 전체 문서에 자동 확장하지 않으며 여러 구역은 조회한 각 구역에 명령을 보낸다.

원본이 그림·그러데이션·무늬·투명도·혼합 채움·3D/대각선/중심선 등 고급 효과이면 변경·삭제를 모두 거절한다. HWP3 계보, 잘못된 자산 참조, 두 개보다 많은 추가 쪽 배경 항목도 읽기 전용이다. 기본 배경과 별도 개체/바탕쪽의 색은 구분한다. 표·개체의 배경까지 변경한 것으로 표시하지 않는다.

## 레이어와 보존

공통 wire schema는 본문 4종과 구조·서식 16종, 총 20종이다. 공개 DTO `Structure.sections[].pageBackgrounds`가 현재 미저장 배경 종류·색·쪽 표시 범위·편집 가능 여부·거절 이유를 전달한다. 기존 저장 기록에서 이 선택 필드가 없는 경우는 유지하지만 새 명령은 조회되지 않은 대상에 실행하지 않는다. 변경 비교 화면에도 배경 설정을 표시한다.

도메인은 대상·필수 값·색 형식·지원 여부를 검사한다. native adapter는 Rust의 원본 검사를 다시 호출하고 원본 토큰을 내부에서만 사용한다. 모델이 토큰·자산 번호·스크립트를 보내면 계약 위반으로 거절한다. GPT·Claude·Gemini·CLOVA·호환 API 모두 같은 계약과 지원 안내를 사용한다.

Rust의 `getAgentPageBackground`/`setAgentPageBackground`는 일반 JSON 조회에서 빠지는 alpha·혼합 채움·고급 효과까지 실제 IR에서 확인한다. 모든 대상의 검사를 마친 뒤 공유 BorderFill을 직접 수정하지 않고 복제한 채움 자원을 등록한다. 원래 SectionDef와 각 홀짝 항목의 비채움 속성을 그대로 두고 새 자원 참조만 바꾼다. 같은 색이나 이미 없는 배경은 새 자원을 만들지 않는다. 입력 오류·오래된 native 토큰은 변경 전에 거절한다.

기존 사본 적용·저장 보존·재열기 검사 후 실제 문서에 적용한다. 기존 요청 snapshot·undo/redo·현재 형식 복구 바이트·부분 적용 실패 차단을 재사용한다. 원본 확인이나 저장 검사 실패를 우회하지 않는다. 일반 getters로 확인하지 못하는 XML/바이너리 전체 보존을 보장하는 기능은 아니다.

## 검증과 남은 작업

전용 실제 Rust/WASM 검사와 Edge 검사는 홀짝별 설정 보존, 첫 쪽 표시, 변경 비교·요청 되돌리기/다시 실행, 안전 저장·재실행, native 입력/토큰 거절, 실제 쓰기 이후 실패 복원과 오래된 모델 응답 거절을 대상으로 한다. 합성 문서와 로컬 provider를 사용하며 사용자 문서·키 저장소·기존 서버를 유지한다. 유료 모델의 판단 품질이나 실제 한글 비교로 계산하지 않는다.

단위 429개·제공자/서버 52개·전용 실제 엔진 16개와 기존 엔진 회귀 256개·전용 실제 Edge 채팅 9개가 통과했다. TypeScript와 9개 모듈·232개 소스 경계도 통과했다. 전체 브라우저 회귀와 실행 묶음 검사를 마친 뒤 최종 수치와 커밋을 추가한다. 그림·그러데이션 등 고급 쪽 배경의 Agent 제어, 테두리/바탕쪽 Agent 명령, 외부 MCP, 구역 생성·삭제, 개체·복잡한 표, 전체 한글 기능과 조판 비교는 남는다. 반복 작업의 새 배경 명령 기록도 별도다. 문서화된 전체 범위가 끝나지 않았으므로 자동 계속 작업을 유지한다.
