# Agent 구역 합치기

2026-10-14. 기존 Delete/Backspace 구역 경계 엔진을 Agent에 연결한다. 실제 한글 직접 비교는 마지막 일괄 검수로 미룬다.

## 범위와 계약

`merge_sections {rightSection}`은 현재 뒤 구역의 0부터 시작하는 인덱스(최소 1)를 받는다. 바로 앞 구역의 마지막 문단과 뒤 구역의 첫 문단을 이어 붙이고 뒤 나머지 본문을 순서대로 이동한다. 두 텍스트와 글자 서식을 유지하며 문단 모양은 앞 문단을 따른다. 합친 경계 문단은 Unicode 글자 4,000자 이하이며 빈 경계도 지원한다.

뒤 구역의 용지·여백·단·탭·배경·번호 설정은 제거되고 앞 구역 설정을 따른다. 그림 배경 역시 앞 배경이 적용된다. 모델 계약과 변경 비교에 이 의미를 명시한다. 다른 구역의 본문·설정·그림 자산을 유지한다. 본문 있는 구역 전체 삭제와 구분한다.

공통 편집 계약은 25종이다. `Structure.sectionMergeAvailable`은 Native API 존재 여부이며 모든 원본 지원을 뜻하지 않는다. 두 대상 구역의 한 단·모든 본문 editable·순서·조회한 제어 정보와 바탕쪽을 검증한다. 표·개체·필드·머리말/꼬리말·감추기·줄 번호·바탕쪽·혼합 서식 원본은 거절한다.

한 요청에 합치기 하나만 허용한다. 다음 요청은 이동한 ID를 다시 읽는다. 반복 기록·자동 저장을 하지 않는다. adapter는 실제 전체 원문과 Native 구조를 재검증하고 기존 staged merge를 호출한다. 반환 커서·결합 본문·개수·앞 설정과 남은 설정을 대조한다. 설정 비교에서 전체 문서로부터 계산한 빈 구역 삭제 가능성만 분리한다. 엔진 원본 검사·현재 형식 사본 preflight·저장 보존 검사를 완화하지 않는다.

하나의 snapshot을 통해 적용하고 커서는 기존 앞 경계 문단 끝으로 이동한다. 요청 undo/redo·변경 비교·생성 중 사용자 변경 거절·정확한 실패 복원·안전한 저장·로컬 보기 복원을 공통 경로로 연결한다. 엔진 패치와 참조 저장소는 변경하지 않는다.

## 검증과 남은 범위

단위는 계약·capability·인덱스·금지 인자·단독 실행·양쪽 원본·Unicode 한도·반복 거절·오래된 원문을 검사한다. 실제 WASM은 HWP/HWPX 두 경계·서식·탭·서로 다른 설정·빈 경계·그림·커서·snapshot undo·저장 재열기·미지원·거짓 성공·split 후 merge를 검사한다. 실제 Edge는 네 provider의 로컬 합성 응답으로 모델 선택·비교·undo/redo·저장·파일 커서·후속 요청·거절·실제 변경 후 실패 복원·지연 충돌·그림·재실행을 검사한다. 결과는 검증 완료 후 갱신한다.

복잡한 경계/상속·바탕쪽·개체·필드·다단·줄 번호·혼합 원본, 여러 경계 일괄 합치기, 본문 있는 구역 전체 삭제와 반복 기록은 남는다. 유료 모델 품질·실제 한글 조판·전체 동등성은 미검증이며 자동 계속 작업을 유지한다.
