# Agent 기존 머리말·꼬리말 기본 글자 서식

2026-10-14. 68번의 기존 텍스트 수정/원본 보호를 재사용해 글자 서식을 연결한다. 참조 저장소와 Rust 엔진은 변경하지 않는다.

## 계약과 범위

27번째 공통 명령 `format_header_footer {section,story,pageKind,originalText,properties}`는 현재 저장된 한 문단 균일 글자 서식 정의 전체에 적용한다. 글자가 있어야 하며 원문이 정확히 일치해야 한다. 한 요청에 하나만 허용한다. 대상이 되는 양쪽/홀짝 머리말 또는 꼬리말을 명시하고, 상속되어 보이는 정의와 현재 구역 저장 정의를 구분한다.

properties는 bold·italic·underline의 참/거짓, fontSizePt 1~200, color #RRGGBB만 지원한다. 실제 크기는 Native의 0.01pt 단위로 반올림한다. 요청한 속성만 전달한다. 원문과 문단 모양·다른 종류/구역·감추기·요청하지 않은 글자 속성을 유지한다. 조회 문맥은 실제 굵게·기울임·밑줄·크기·색을 제공하고 변경 비교는 한글로 표시한다.

글꼴 종류·장평/자간·문단 모양 변경, 빈 정의의 입력 서식, 필드·개체·혼합/여러 문단·긴 원본·정의 생성/삭제·반복 기록은 지원하지 않는다. 자동 저장하지 않으며 글자 서식 변경으로 감추기나 홀짝 덮어쓰기를 해제하지 않는다.

## 연결과 보호

Domain에서 현재 정의·편집 가능성·원문·조회된 글자 모양·인자·단독 실행을 검사한다. Adapter는 원본을 재조회한 뒤 기존 Native setter에 동일 텍스트와 내부 토큰을 넘겨 실제 IR/스타일을 변경 없이 검증한다. 이어 기존 applyCharFormatInHeaderFooter를 전체 문단에 실행한다. 토큰은 모델과 receipt에 노출하지 않는다. Native 원본 제한을 완화하거나 파일을 별도로 고치지 않는다.

결과는 텍스트·다른 정의·현재 다섯 속성과 조회 가능한 미요청 글자 속성을 대조한다. 현재 형식 사본 preflight와 글자/문단 모양 저장 보존 검사를 거친 뒤 공통 snapshot으로 적용한다. 요청 undo/redo·실문서 변경 뒤 실패 복원·텍스트가 같더라도 버전이 바뀐 결과 거절·안전한 저장·로컬 업무 복원을 연결한다. 기존 저장 보존 검사가 읽지 못하는 미해석 원본 레코드와 혼합 run 전체는 여전히 한계다.

## 검증과 남은 범위

단위는 27종 계약·5개 속성·참/거짓·물리 크기/색·한도·원문·단독 실행·기록 거절·읽기 쉬운 비교를 검사한다. 실제 WASM은 HWP/HWPX의 여섯 종류·서식/텍스트/문단 보존·undo·저장 재열기·소수 크기/해제·후속 문구 수정·장평/자간/음영/첫 쪽 감추기 보존·미지원/거짓 성공을 검사한다. 실제 Edge는 네 제공자의 합성 응답으로 같은 동작, 늦은 실패 복원·서식만 바뀐 동시 편집 충돌·실제 SVG와 재실행을 검사한다.

한글 직접 비교와 유료 모델 품질은 마지막 별도 검수다. 고급 머리말·꼬리말, 동적 필드, 생성/삭제, 문단 모양/글꼴 종류와 전체 한글 동등성은 남는다. 전체 문서화된 구현 범위는 미완료이며 자동 계속 작업은 유지한다.

## 마지막 한글 일괄 비교 절차

1. `agent-header-format-native/before-{header|footer}-{both|odd|even}.{hwp|hwpx}`와 대응하는 `formatted-*`를 한글 2024에서 각각 연다. 매니페스트로 실제 파일을 식별한다.
2. 요청한 굵게·기울임·밑줄·크기·색과 유지되어야 하는 원문·문단 모양·본문·다른 정의·첫 쪽 감추기를 확인한다. 양쪽 정의에 홀짝 정의가 덮어쓰는 경우에는 지면 표시만으로 판정하지 말고 저장 정의 자체도 확인한다.
3. `false-flags-followup.hwpx`에서 서식 해제와 10.13pt 반올림·후속 문구를, `retained-font-effects.hwpx`에서 기존 장평/자간/음영 보존을 확인한다.
4. 브라우저 결과 파일의 채팅 적용 결과와 저장 문서를 함께 비교하고 결과를 별도 기록한다. 현재 한글 직접 비교 상태는 NOT_RUN이며 자동 검사를 한글 호환성 전체 보증으로 해석하지 않는다.
