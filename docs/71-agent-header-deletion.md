# Agent 기존 머리말·꼬리말 저장 정의 삭제

2026-10-14. 29번째 공통 명령 `delete_header_footer {section,story,pageKind,originalText}`는 현재 구역에 저장된 한 문단 단순 머리말/꼬리말 정의 하나를 제거한다. 텍스트를 비우는 명령과 구분한다. 양쪽/홀짝·머리말/꼬리말을 정확히 지정하며, 빈 기존 정의도 삭제할 수 있다. 이미 없으면 성공으로 표시하지 않는다.

앞 구역의 상속 또는 다른 홀짝 정의가 보일 수 있다. 삭제는 모든 지면에서 머리말/꼬리말을 감추는 명령이 아니고, 새 빈 덮어쓰기 정의도 만들지 않는다. 요청 결과에는 이 구분을 안내한다.

첫 범위는 root secd/cold/head/foot 제어만 있는 일반 본문 문서다. 문서의 모든 저장 머리말/꼬리말이 Native 일반 원본 검사에 통과해야 한다. 다른 구역의 혼합/복잡한 정의도 삭제 가능성을 차단한다. 현재 원본의 editable과 조회된 deletable이 모두 참이어야 한다. 표·개체·필드·다른 root/중첩 제어가 있거나 원본이 여러 문단/혼합/긴 텍스트/탭/필드·개체라면 거절한다. 원본 보호 조건은 완화하지 않는다. Native 원본·private token을 동일 텍스트 setter로 검증한 뒤 기존 deleteHeaderFooter를 호출한다. 토큰은 모델/기록에 넣지 않는다.

본문 전체 run의 보존 증거를 추가로 대조해 중간 글자만 잘못 바뀌는 경우도 거절한다. 본문 텍스트·글자/문단/스타일·대상 밖 저장 정의·용지/단/배경/바탕쪽·줄 번호·감추기를 대조한다. 삭제에 따른 본문 제어 제거·레이아웃 쪽 위치·재계산된 빈 구역/줄 번호 편집 가능성만 동적 결과로 구분한다. 디스크를 별도로 수정하지 않고 공통 사본 preflight/현재 형식 저장 보호·snapshot undo/redo·실문서 실패 복원·버전 충돌·안전한 저장·업무 복원을 사용한다. 삭제는 단독 명령이고 반복 기록·생성·복잡한 문서·상속 차단은 미지원이다. 편집 중인 머리말 모드에서는 기존 Agent 실행 모드 제한을 따른다.

전용 단위·실제 WASM·격리된 Edge와 네 제공자 합성 응답을 검사한다. 한글 2024 직접 비교와 유료 모델 품질은 마지막 별도 검수다. 확정 결과는 검사 후 기록한다. 전체 문서화된 구현 범위는 미완료이며 자동 작업은 유지한다.
