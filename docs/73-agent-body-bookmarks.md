# 73. AI 일반 본문 점 책갈피

2026-10-14. 현재 열린 문서에 `add_bookmark`, `rename_bookmark`, `delete_bookmark` 세 명령을 연결한다. 한 요청에 하나만 실행하며 자동 저장과 반복 기록은 지원하지 않는다. 공통 계약은 33종이다.

구역/단 정의와 본문 점 책갈피만 있는 일반 문서가 대상이다. 추가는 현재 편집 가능한 일반 본문 문단과 0부터 시작하는 Unicode 글자 위치를 받는다. 이름은 빈 값·제어문자 없는 올바른 Unicode 100자 이하이고 중복을 금지하며 200개 이내에서 추가한다. 이름 변경·삭제는 최신 목록의 유일한 이름을 사용한다. Native 인덱스는 앱이 다시 조회하며 모델이 지정하지 않는다.

기존 책갈피 문단의 본문 AI 편집 보호를 유지한다. 해당 문단에 다른 책갈피를 추가하거나 본문을 바꾸는 기능은 이번 범위가 아니다. 기존 책갈피 이름 변경/삭제는 가능하다. 다른 일반 문단에 별도 이름을 추가할 수 있다. 표·개체·필드·머리말/꼬리말 등 다른 제어가 있는 문서는 책갈피 편집을 거절한다. 범위 책갈피·하이퍼링크·자동 이동은 지원하지 않는다. 조회 실패/한도 초과를 ‘책갈피 없음’으로 표시하지 않는다.

Application→Domain 공통 계약→rhwp Adapter→현재 Native 문서를 사용한다. 디스크 파일을 따로 고치지 않는다. 원본 이름/위치와 본문 전체 run·문단/글자 서식·다른 제어·설정을 대조한다. 구조 변경으로 계산되는 도구 지원 가능성과 페이지 위치만 저장 설정과 구분한다. 요청 snapshot undo/redo·사본 preflight·실패 복원·버전 충돌·현재 형식의 보존 검사·안전한 저장·업무 복원을 연결한다.

## 검사 상태

단위·고정 WASM·격리된 Edge에서 양 형식과 네 제공자 합성 응답을 검사한다. 실제 한글 2024 비교와 유료 모델 품질은 최종 별도 검수다. 전체 편집기 기능 구현은 아직 완료되지 않았다. 확정 결과는 아래와 같다.

## 후속 제한: 머리말/꼬리말 쪽 필드

Native의 `insertFieldInHf`로 쪽/전체 쪽 수를 삽입하는 기능은 아직 AI에 노출하지 않는다. 메모리의 U+0015/U+0016 표식이 저장 과정에서 AutoNumber 제어와 자리 공백으로 변환되어, 재열기 텍스트가 달라지고 기존 보존 검사가 차단한다. 의미상 필드와 위치/서식이 보존되는지 검증하는 별도 계약이 필요하다. 보호 검사를 완화하거나 성공으로 표시하지 않았다. 한글 직접 비교도 미실행이다.
