# 75. AI 문단 기본 테두리와 배경

2026-10-14. `format_paragraph_decoration`를 공통 계약에 추가한다(35종). 일반 본문 문단의 네 방향 기본 테두리·단색 배경·테두리 간격·연결/여백 무시를 부분 변경한다. 요청하지 않은 속성은 유지하며, 같은 값은 쓰기에서 제외한다. 서로 다른 문단의 전용 명령만 최대 30개를 한 요청/undo로 묶는다. 다른 명령 혼합·동일 대상 중복·반복 기록·자동 저장은 지원하지 않는다.

선은 없음/실선과 한글에 저장 가능한 16개 굵기(0.1·0.12·0.15·0.2·0.25·0.3·0.4·0.5·0.6·0.7·1·1.5·2·3·4·5mm), RGB 색을 지원한다. 선 없음은 0.1mm/#000000 기본 값으로 지정한다. 배경 종류 none/solid와 색은 함께 보내며 none은 #ffffff다. 테두리 간격은 좌/우/위/아래 각각 0~20mm이고 연결/여백 무시는 참·거짓이다. 문단 배경 지우기는 쪽 배경 지우기와 구분한다.

## 원본과 계층

Domain은 현재 본문·원본 가능성·속성·단위·묶음을 검사한다. Snapshot `paragraphDecorationSources`는 지원 여부/이유만 전달한다. 원본 토큰·엔진 객체 핸들은 모델에 노출하지 않는다. 구조 조회의 참조 ID를 명령 인자로 받지 않고 BF/PS 대상은 앱이 현재 문단에서 다시 확인한다. 현재 문단의 기존 원본을 다시 읽고 Adapter→Native API로 실행하며 디스크 파일을 따로 수정하지 않는다.

Rust `getAgentParagraphDecoration`/`setAgentParagraphDecoration`는 기존 일반 본문/탭 원본 검사와 원문·서식 토큰을 사용한다. 실제 BF의 attr/효과/추가 데이터·색/채움 원본을 검증하고, 기존 정의를 복제해 공유하는 다른 문단이나 표·쪽을 바꾸지 않는다. 알 수 없는 바이너리 추가 데이터는 거절하며, 알려진 빈 채움 추가 크기 0 필드가 생략된 표현만 구분한다.

한글 기본 blank2010 원본에는 보이지 않는 대각선의 선모양 SOLID와 COLORREF 색 없음 0xffffffff가 실제로 저장돼 있다. 이 비활성 정의와 빈 winBrush는 고급 가시 효과로 오인해 삭제하거나 24비트 색으로 변환하지 않는다. 원본의 알려진 표현을 인식하고 그대로 복제하며, 요청 밖 BF 속성 전체를 Native에서 다시 대조한다. 같은 배경을 다시 요청한 경우 Domain이 그 항목을 제외해 빈 채움 표현을 불필요하게 다시 쓰지 않는다. 실제 대각선/3D/그림/그러데이션/투명도/무늬/비기본 선·알 수 없는 attr/원본 데이터는 읽기 전용이다.

Adapter는 의도한 속성을 제외한 전체 문서 보존 증거를 대조한다. 사본 preflight·현재 형식 저장 검사·요청 snapshot undo/redo·일부 적용 후 전체 복원·문서 버전 충돌·안전한 저장·업무 복원은 기존 공통 경로를 사용한다. 비교 창에 테두리/배경·간격·연결 상태를 표시한다.

## 범위와 검사

일반 본문·균일 글자 서식·지원되는 기본 탭/테두리 정의가 대상이다. 필드·개체·실제 탭 문자·혼합/특수/고급 원본, 임의 선 종류·사용자 임의 굵기·그림/그러데이션/무늬 배경·고급 효과는 미지원이다. 기존 지원 보호를 완화하거나 고급 원본을 기본 속성으로 조용히 축소하지 않는다. 실제 한글 2024 직접 비교와 유료 모델 품질 검사는 최종 별도 단계다. 전체 문서화 범위는 미완료이며 자동화를 유지한다. 확정 자동 검사와 검수본 위치는 아래와 같다.
