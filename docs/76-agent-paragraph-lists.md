# 76. AI 문단 번호·글머리표의 기존 정의 적용

2026-10-14. `set_paragraph_list`를 제공자 중립 계약에 추가한다(36종). 현재 열린 문서의 저장된 번호/글머리표 정의를 조회하고 그 정의를 일반 본문 문단에 적용한다. 번호는 1~7수준(wire level 0~6), 글머리표는 첫 수준(level 0), 해제는 none/definitionId 0/level 0이다. 실제 본문에 번호 문자열을 붙이거나 디스크를 별도로 수정하지 않는다.

`Snapshot.listCatalog`는 현재 문서의 정의 ID·번호 형식 문자열·시작 값·글머리표 문자를 읽기 자료로 전달한다. ID는 현재 카탈로그에서 선택하는 공개 참조이며 새 정의를 만들거나 다른 문서의 ID를 추측할 수 없다. `paragraphListSources`는 본문별 지원 여부/이유만 노출한다. 비공개 토큰과 전체 Native 객체는 모델에 보내지 않는다. 카탈로그가 없는 문서나 저장된 글머리표가 없는 새 문서에 글머리표를 요청하면 실제 기능 미지원으로 안내한다.

서로 다른 문단의 전용 명령만 최대 30개를 한 요청과 undo로 처리한다. 같은 대상 중복·다른 명령 혼합·반복 매크로·자동 저장은 거절한다. 사용자 직접 편집과 AI는 같은 열린 상태를 사용한다. 후속 요청은 다시 현재 상태를 읽는다.

## 원본 보존

Domain은 대상·카탈로그·인자·수준·원본 가능성과 no-op을 검사한다. Adapter는 현재 원문·번호 상태·카탈로그를 재확인하고 전체 문서 보존 증거를 비교한다. Rust는 일반 본문/균일 글자/기본 탭 원본 검사, 문단·서식·공유 번호 정의를 포함한 원본 토큰, 엄격한 필드·정의 범위 검사를 수행한다. 기존 정의를 수정·재생성하지 않으며 적용 실패는 Native snapshot으로 복원한다. 공통 사본 preflight·현재 형식 저장 검사·요청 undo/redo·버전 충돌·전체 복원 경로를 사용한다.

번호의 이어짐은 앞 문단에 따라 계산된다. 따라서 다른 번호 문단의 화면상 순번이 함께 달라질 수 있지만 그 문단의 저장 속성을 변경하는 것은 아니다. 계산된 numberingRestartMode/StartNum과 실제 저장된 restart 지시를 구분한다. 계산값만 적용 전후 의도 비교에서 제외하고 Native에서 별도로 읽은 모든 저장 restart를 완전히 대조한다. 저장 검사도 문단별 storedNumberingRestart를 비교한다. 명시적 다시 시작을 새로 만드는 명령은 제공하지 않는다.

기존 `getStyleDetail`은 저장된 스타일에 번호가 없으면 그 스타일을 쓰는 실제 문단의 번호 모양을 섞어 반환한다. 이를 저장 정의 변경으로 오판하지 않도록 `getStoredStyleDetail`을 추가해 보존 검사에서 저장된 스타일 자체를 읽는다. 번호/글머리표 IR 정의도 저장 전후 확인한다. 그림/체크 글머리표는 카탈로그 선택지에서 제외하고 Native에서도 거절한다. 기존 정의의 잘못된 글자 모양 참조도 Native에서 거절할 수 있다. 원본 바이너리·XML 확장 전체의 보존을 입증하는 것은 아니다.

## 현재 제한과 후속 항목

일반 본문만 지원한다. 개요·확장 수준·명시적 다시 시작·실제 탭 문자·혼합 서식·책갈피/필드/표/개체가 있는 대상은 보호한다. 번호 모양 생성/수정·새 문자/그림/체크 글머리표 생성·번호 재시작·개요 체계와 자동 목차는 후속 항목이다. 예외 원본을 조용히 기본 값으로 축소하지 않는다. 실제 한글 2024 조판 비교와 유료 모델 품질 검사는 최종 일괄 검수로 남긴다.
