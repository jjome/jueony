# 80. 저장된 구역 개요 수준 적용과 해제

2026-10-14. `set_paragraph_outline`을 제공자 중립 계약에 추가한다(40종). 현재 구역에 저장된 유효한 번호 정의를 변경하지 않고 일반 본문에 개요 1~7수준을 지정·변경·해제한다.

```json
{"kind":"set_paragraph_outline","target":"s0p0","enabled":true,"level":0}
```

모델의 level은 0~6이다. enabled=false는 현재 지원되는 개요 문단에서 level=0으로 요청한다. 서로 다른 문단의 개요 전용 명령만 최대 30개 묶어 한 요청/undo로 적용한다. 중복 대상·다른 종류의 혼합 명령·같은 수준/참조 no-op은 거절한다.

## 편집·보존 구조

Snapshot.paragraphOutlineSources는 대상별 editable/reason과 저장된 구역 개요 definitionId만 제공한다. 번호 형식은 기존 listCatalog를 조회해 중복 문맥을 줄인다. 비공개 원문/서식 토큰·핸들·파일 경로는 모델에 보내지 않는다. Native는 기본 탭·균일 글자 서식·제어/필드/표식 없는 일반 본문, 명시적 restart 없음, 7수준과 유효한 번호/글자 모양 참조를 검사한다. 구역과 다른 개요 정의를 직접 참조하는 원본은 보호한다.

켜기는 문단 headType=Outline / numberingId=0 / 지정 수준을 저장한다. 0은 정의 없음이 아니라 현재 구역의 outline_numbering_id를 따르는 엔진의 기존 경로다. 끄기는 None/0/0이다. 구역 개요 정의와 전체 번호/글머리표 자원, 본문 글자·여백·탭·테두리·배경·스타일·저장 restart를 유지한다. 선택 수준의 번호 형식이 비어 있으면 적용하지 않는다.

Rust는 원본 토큰과 자원·구역 참조를 대조하고 문서/이벤트 snapshot으로 실패를 복원한다. Adapter는 본문·번호·카탈로그와 구역 참조를 다시 읽고 기대 문단 속성만 변경한 전체 보존 증거와 대조한다. 계산된 번호 이어짐 getter와 실제 저장 restart 필드는 분리한다. 공통 사본 preflight·현재 형식 저장 재열기·실문서 snapshot undo/redo·동시 버전 충돌 검사를 사용한다. 두 번째 실문서 적용에서 실패하면 첫 문단을 포함해 요청 전체를 복원한다.

## 실제 지원 범위

현재 저장된 구역의 번호 모양을 사용한다. 구역의 개요 모양을 새로 만들거나 다른 정의로 바꾸지 않는다. 이 문서의 번호 모양에 따라 표시가 달라지며 모든 수준이 자동으로 1.1.1 같은 다중 경로를 표시한다고 약속하지 않는다. 유효한 저장 정의가 없는 구역은 렌더러 내장 기본 모양으로 조용히 대체하지 않는다. 이는 향후 별도 도구 범위다.

기존 개요 스타일 적용과 구분하여 문단의 개요 속성만 바꾸므로 본문 글꼴·여백·스타일 이름을 자동 통일하지 않는다. 수준별 여백이나 제목 글꼴 변경은 기존 문단/글자 서식 또는 스타일 도구로 따로 요청한다. 개요/표 차례·목차 생성, 8~10수준, 임의 개요 형식, 글상자/표/필드/책갈피/실제 탭/혼합 글자 서식, 명시적 문단 restart 저장·반복 매크로·자동 저장은 미지원이다. 한글 2024 전체 개요 기능 동등성은 아직 판정하지 않았다.

## 실행과 검증

검수본은 `build/jueony-agent-outline-20261014-v2/Start-Review.cmd`, 주소는 `http://127.0.0.1:4286/`로 준비한다. 이전 실행 창·서버·사용자 문서는 유지한다. 한글에서 열 합성 HWP/HWPX는 review-documents/agent-outline에 포함한다. 네 제공자는 로컬 합성 프로토콜 검사이며 실제 유료 모델 호출이 아니다. 실제 한글 직접 비교는 마지막 일괄 단계로 유지한다. 전체 범위는 미완료다. 최종 검사 수와 해시는 아래에 추가한다.

개요 연결 검수 중 기존 getSectionDef 조회에서 개요 정의 참조가 빠져 있음을 확인했다. 별도 읽기 getAgentOutlineDefinition을 추가하여 모든 구역의 저장 전후 참조를 비교한다. 복잡한 첫 문단 때문에 일반 본문 편집 자격이 없더라도 참조 조회는 가능하다. 재열기 사본의 outlineShapeIDRef만 바뀐 실제 HWPX를 만들어 기존 구역 조회는 같아도 새 보존 증거가 저장을 차단하는지 검사한다. 첫 4284 후보는 보존하고 최종 수정본은 4286 별도 묶음으로 준비한다.
