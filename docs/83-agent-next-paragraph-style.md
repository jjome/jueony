# 83. AI 다음 문단 스타일 연결과 실제 Enter 흐름

2026-10-14. 제공자 중립 계약에 `set_next_paragraph_style`을 추가한다(43종). 기존 문단 스타일 정의 하나의 다음 스타일 연결만 바꾸고 기존 문단의 텍스트·스타일 ID·서식은 유지한다. 이후 일반 본문 문단 끝에서 Enter를 누르면 새 문단이 지정한 스타일을 사용한다. 문단 중간에서 나누면 원래 스타일을 유지한다.

```json
{"kind":"set_next_paragraph_style","styleId":22,"nextStyleId":23}
```

## 계약과 모듈 경계

공통 wire schema는 두 ID만 받는다. Domain은 조회한 type=0 대상과 styleNextSources/styleNextTargets를 검증하고, Adapter는 실제 저장된 연결·모양·이름·영어 이름·언어·잠금의 해시와 카탈로그를 다시 대조한다. 원본과 목적지 모두 요청 도중 달라지면 적용하지 않는다. Snapshot의 currentNextStyleId를 조작해도 실제 저장 값이 이미 같으면 no-op으로 거절한다. 해시는 구조 검증용이며 권한 토큰이나 Native 핸들이 아니다.

이름 변경과 공유하는 agent-style-source adapter에 안전한 메타데이터 편집 판정을 모았다. Native getAgentStyleMetadata가 확인한 canonical HWP 레코드, 잠금 해제된 문단 정의만 허용한다. 바탕글(ID 0)은 변경 원본으로 보호하지만 다음 스타일의 목적지로는 허용한다. 자기 연결과 A→B→A 순환은 유효하며 각 요청에서 연결 하나씩 바꾼다. 새 정의가 없으므로 256개 상한에서도 가능하다. 글자 스타일·양식 잠금·비정규 확장 원본은 원본과 목적지 양쪽에서 보호한다. 필드가 있는 문서는 이 명령에서 보호한다.

한 요청에 이 명령 하나만 허용한다. 다른 명령과 혼합하거나 매크로로 실행하지 않는다. 전체 보존 증거에서 기대한 nextStyleId 한 값만 바뀌었는지 확인하며, 본문·서식·자원·다른 스타일의 부수 변경과 잘못된 성공 반환은 실패다. 사본 preflight와 현재 형식 export/reopen 후 실문서에 반영하고 요청 undo/redo 및 실패 복원을 제공한다. 현재 커서를 유지하고 저장은 사용자가 별도로 실행한다. 지연 모델 응답이 최신 사용자 변경을 덮어쓰지 않는다.

Public Structure.styleLinks로 이름과 다음 연결을 분리해 제공한다. 변경 비교와 Agent 문맥은 ‘Enter 후 업무 본문’처럼 이름으로 다음 스타일을 표시한다. 기존 styles의 ID/name/type 계약은 유지한다. UI와 provider는 Native 형식에 의존하지 않는다. 기존 style-flow의 문단 끝 split/apply 경로를 재사용하며 엔진 패치를 추가하거나 보호 기준을 완화하지 않았다.

## 검증 범위

자체 합성 문서에서 ‘업무 제목’ 15pt/굵게 → ‘업무 본문’ 11pt/보통을 연결한다. 실제 Edge 키보드 End/Enter로 전환하고 본문을 입력한 뒤 실제 HWP/HWPX로 저장·재열기한다. 이모지가 들어간 문단 끝에서도 UTF-16 위치와 실제 문서 길이가 맞는지 검사한다. 중간 Enter는 제목 스타일을 유지한다. 바탕글 목적지·자기 연결 복원·순환 연결, 최대 256개, 보호 원본/목적지, 요청 중 소스/목적지 변경, 잘못된 성공·부분 변경 복원·커서·업무 재실행도 검사한다.

네 제공자 검사는 실제 adapter와 합성 프로토콜 응답을 연결한 검사다. 유료 모델 호출·품질 검수는 미실행이다. 새 엔진 빌드와 Native Rust unit tests 없이 기존 570603 엔진의 실제 WASM을 재사용한다. 한글 2024 직접 GUI/출력 비교는 마지막 일괄 검수로 남겨 둔다. 검증한 일반 본문 범위를 표 셀·모든 개체·모든 단축키와 전체 한글 동등성으로 확대 해석하지 않는다.

## 실행과 남은 작업

검수본은 `build/jueony-agent-style-next-20261014/Start-Review.cmd`, 주소 `http://127.0.0.1:4294/`다. 이전 4292/4290 등 검수 서버와 사용자 문서는 유지한다. 성공 편집 결과와 보호/외국어 입력 fixture를 구분해 제공하며 한글 확인 순서와 파일 해시를 기록한다.

스타일의 임의 새 모양·영어 이름/언어/잠금 수정·삭제·상속/STY, 복잡한 표/개체/필드·변경 추적·서명, 명시적 문단 restart의 안전한 저장과 전체 한글 동등성은 아직 남는다. 저장 손실이 있는 명령은 계속 차단하며 미지원 항목을 성공으로 표시하지 않는다. 전체 문서화된 범위가 완료된 것은 아니며 자동화를 유지한다.
