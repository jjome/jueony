# 84. AI 표 쪽 나눔 정책

2026-10-14. 제공자 중립 계약에 `set_table_pagination`을 추가한다(44종). 현재 문서에서 조회한 본문 표 하나의 저장된 쪽 나눔 정책을 바꾼다. 셀의 내용·글자/문단 서식·크기·여백·병합 상태와 표의 배치·기존 제목 행 반복 플래그는 유지한다.

```json
{"kind":"set_table_pagination","target":"s0p1t0","mode":"row"}
```

| mode | 앱의 의미 | Native 값 |
| --- | --- | --- |
| none | 나누지 않기 정책 | 0 |
| cell | 셀 안에서 나눔 정책 | 1 |
| row | 행 사이에서 나눔 정책 | 2 |

이것은 엔진 모델의 TablePageBreak 설정이다. 한글과의 정확한 조판·너무 큰 표의 fallback·모든 쪽 나눔 조건을 동일하게 구현했다는 뜻은 아니다. 기존 serializer의 Native enum/HWPX 문자열 대응을 재사용하며 HWPX의 pageBreak 문자열을 모델이 직접 쓰게 하지 않는다. 실제 한글 2024 지면 비교는 마지막 일괄 검수로 남긴다.

## 계약과 안전 경계

Public Table.pagination에 현재 정책과 기존 repeatHeader를 읽어 주며 Snapshot.tablePaginationSources에 편집 가능 여부·이유·현재 정책·검증 해시를 제공한다. 모델은 기존 표 ID를 사용한다. 새 표 alias는 후속 요청에서 실제 ID를 조회한 뒤 사용한다. Domain은 세 모드·capability·no-op·단독 요청을 검증하고 Adapter는 실제 표의 내용·셀 서식·기하·정책·배치와 해시를 다시 확인한다. 기다리는 동안 사용자 변경이 있으면 오래된 결과를 적용하지 않는다.

처음에는 200셀 이하의 본문 단순 표만 지원한다. 병합·중첩·혼합 글자 서식·보호 셀/표·캡션·글자처럼 취급·겹침과 필드 문서는 보호한다. 쪽 나눔 변경이므로 셀을 비우거나 서식을 단순화하여 허용하지 않는다. 실제로 읽지 못하거나 지원하지 않는 대상은 capability를 내리지 않거나 editable=false로 안내한다. 외부 MCP 서버를 새로 만든 것은 아니며 기존 내부 편집 명령 계층에 연결했다.

기존 setTableProperties에 pageBreak 한 값만 전달한다. 사본 preflight와 현재 형식 export/reopen을 먼저 검사한다. 실문서 적용 뒤 전체 보존 증거에서 정확히 대상 표의 pageBreak 한 값만 바뀌었는지 대조한다. 셀/본문·제목 행 반복·위치·다른 표·스타일·자원 등 요청 밖 변경과 잘못된 성공/no-op은 거절하고 실문서를 복원한다. 요청 단위 undo/redo, 현재 본문 커서 유지, 직접 후속 입력과 파일 저장을 연결했다. 한 요청에 이 명령 하나만 허용하며 매크로와 자동 저장은 지원하지 않는다.

기존 TextWrap control 비트는 setTableProperties 이후 실제 common.text_wrap과 다를 수 있었다. 기존 serializer와 보존 검사처럼 resolved textWrap 값을 검증 해시에 사용한다. 실제 배치 값 변경은 계속 거절한다. 물리 캐시의 불일치를 무시하기 위해 전체 배치 검사를 제거하지 않는다. 실제로 outerLeft를 바꿀 수 없는 HWPX 합성 원본은 위치 오염 주입으로 인정하지 않고 변경 가능한 vertOffset으로 반례를 검사했다.

## 구현과 검증

UI/Agent는 public DTO와 공통 wire 계약을 사용하고 Native 숫자·JSON 호출은 rhwp adapter에 둔다. 비교 창과 저장된 작업 기록은 ‘셀 안에서 나눔’·‘행 사이에서 나눔’처럼 정책을 표시한다. 제목 행 반복은 현재 값을 읽어 표시하되 변경 기능은 아직 미지원이라고 안내한다. 단순히 repeatHeader=true로 바꾸는 것을 제목 셀/반복 조판 전체 구현으로 표시하지 않는다.

실제 WASM으로 HWP/HWPX 각 세 모드·여러 표·후속 전환·원래 없음으로 복원·요청 사본/저장 재열기와 snapshot 복원을 확인한다. 기존 반복/제목 셀 플래그 보존, 후속 구역의 flattened 표 위치, 캐시 비트와 실제 배치 차이, 보호/오래된 대상·잘못된 성공·부수 변경 거절을 포함한다. 자체 24행·48셀 예시는 여러 쪽의 SVG 렌더와 양 형식 파일/셀 재열기를 검사한다. 같은 엔진의 렌더·재열기이므로 실제 한글 지면의 독립 증거로 표시하지 않는다.

Edge에서는 네 제공자의 실제 adapter와 합성 프로토콜을 연결해 모델/명령 반영·변경 비교·undo/redo·저장·실패 복원·지연 요청 충돌·본문 커서/직접 입력·업무 복원을 검사한다. 실제 유료 모델 호출과 한글 GUI 검수는 미실행이다. 엔진 570603을 재사용하며 이번에 새 엔진 컴파일이나 Native Rust unit tests를 수행하지 않는다.
