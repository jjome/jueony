# 85. 첫 제목 행 지정·반복과 Agent/수동 창

2026-10-14. 첫 행 전체를 제목 행으로 지정·해제하고 여러 쪽에 반복하는 기능을 수동 창과 Agent에 연결한다. 표 반복 플래그만 켜는 것이 아니라 첫 행의 모든 셀에 isHeader를 지정한다. 제공자 중립 계약은 45종이다.

```json
{"kind":"set_table_header","target":"s0p1t0","headerRows":1,"repeatHeader":true,"paginationMode":"row"}
```

## 지원 범위와 계약

headerRows=0은 제목 표시 해제, 1은 첫 행 전체 지정이다. repeatHeader=true는 headerRows=1, paginationMode=row, 적어도 하나의 본문 행이 필요하다. 반복하지 않는 제목 행은 repeatHeader=false로 지정하고 쪽 나눔은 none/cell/row 중 명시한다. 제목 해제 후에도 반복=false와 유지할 쪽 나눔을 명시한다. 한 요청에서 제목 표시·반복·쪽 나눔을 하나의 snapshot/undo로 적용한다. 같은 설정은 no-op 오류이며 기존 표 ID를 조회한 뒤 단독 명령으로 사용한다. 새 표 alias·명령 혼합·매크로·자동 저장은 지원하지 않는다.

처음에는 200셀 이하의 본문 단순 표를 지원한다. 84번의 보호/병합/중첩/혼합 서식/필드/캡션/글자 취급/겹침 제한을 유지한다. 첫 행 일부만 제목이거나 여러/흩어진 제목 행이 있는 원본은 보호한다. 이들을 한 행으로 조용히 줄이지 않는다. 여러 제목 행의 반복 높이·분할·병합 셀 조판은 별도 구현/검증 과제로 남긴다. 표의 첫 행이 아닌 선택 셀을 제목으로 표시하는 명령도 이번 범위가 아니다.

Public Table.headerRows는 0/1 또는 복합 원본=null을 표시한다. Snapshot.tableHeaderSources는 편집 가능 여부·이유·현재 제목/반복/쪽 나눔과 검증 해시를 제공한다. Domain은 조합·현재 대상·no-op·단독 요청을 검사하고 rhwp adapter는 실제 셀/기하/내용/서식/배치/정책 해시와 원본 상태를 다시 검사한다. Native 숫자·JSON 호출은 adapter에 둔다. LLM/수동 UI는 공통 DTO와 계약을 사용한다.

## 실제 편집과 수동 사용

표 개체 또는 셀 블록 선택 → 표 메뉴 → ‘첫 제목 행·반복’을 연다. 현재 파일에서 설정을 읽는다. 반복을 체크하면 첫 행 전체와 행 단위 쪽 나눔이 함께 선택되며 사용자가 확인할 수 있다. 셀 블록 선택으로 열어도 표 전체의 첫 행을 지정한다는 안내를 표시한다. 취소는 문서를 바꾸지 않는다. 문서·표 선택이 바뀐 창의 확인은 거절한다. 적용 뒤 표 개체/셀 블록 선택을 유지하고 통합 메뉴에도 명령을 노출한다.

수동 창과 Agent는 동일한 validate/execute adapter를 사용한다. 적용 전에 현재 형식 사본 preflight와 export/reopen 검사를 수행한다. 대상 셀의 isHeader와 표 repeatHeader/pageBreak만 달라졌는지 전체 보존 증거로 대조한다. 내용·글자/문단 서식·크기·여백·배치·다른 표·스타일/자원·필드는 유지한다. 두 번째 셀에서 실패해도 첫 셀 변경까지 복원하며 잘못된 성공·추가 제목 셀·본문/서식/배치/자원 오염을 거절한다. 요청/수동 undo/redo·저장·업무 복원을 연결한다.

## 반복 조판의 실제 검증

기존 엔진의 Table.leading_header_rows → 반복 높이 측정/분할 → table_partial의 이어지는 쪽 제목 렌더 경로를 재사용한다. 이번에 엔진 패치나 캐시/보호 조건을 변경하지 않았다. 자체 24행·48셀 문서에서 첫 행 두 셀을 TITLE-Z-0/TITLE-Z-1로 만들었다. 반복을 켠 실제 SVG에서 각 쪽에 각 제목이 정확히 한 번씩 나타나는지 검사한다. 반복을 끄면 제목은 첫 쪽에만 남는다. 제목 외 46개 셀의 고유 항목과 둘째/셋째 줄이 전체 SVG에 각각 한 번씩 나타나는지도 검사한다. 저장된 원본 텍스트/셀은 복제하지 않으며 HWP/HWPX로 저장·재열기해 반복 결과와 플래그를 확인한다. 여러 쪽 화면과 첫 제목 행 설정 창도 별도로 캡처한다.

이것은 실제 WASM과 Edge 편집/렌더 경로의 검증이다. 한글 2024 GUI와 독립 지면/출력 비교는 사용자의 지시에 따라 마지막에 일괄 수행한다. 모든 표/단/쪽 조건에서 한글과 동일하다고 표시하지 않는다. 네 제공자의 actual adapter와 합성 프로토콜로 검사하며 유료 모델 호출·품질 검수는 미실행이다. 기존 엔진 570603을 재사용하고 이번 Native Rust unit tests/새 엔진 컴파일은 수행하지 않는다.

## 실행과 후속 순서

검수본은 `build/jueony-agent-table-header-20261014/Start-Review.cmd`, 주소 `http://127.0.0.1:4298/`다. 이전 4296/4294 등 실행본과 사용자 문서는 유지한다. 자체 성공 문서·반복 on/off SVG·설정/비교/여러 쪽 화면·검증 기록을 함께 제공한다.

다음에는 여러 제목 행의 높이·이어지는 쪽 분할 보존을 별도로 검증한 뒤 확대하고, Agent의 표 크기/여백/테두리·병합/분할과 복잡한 표를 확장한다. 남은 고급 스타일·개체/필드·변경 추적/서명·문단 restart 안전 저장과 전체 한글 동등성은 아직 미완료다. 보호 조건을 완화하거나 미지원 기능을 성공으로 표시하지 않는다. 전체 작업 완료 전까지 자동화를 유지한다.

추가 관찰: 현재 엔진의 row 정책에서도 긴 예시의 행 일부가 다음 쪽으로 이어진다(두 번째 쪽 제목 바로 아래 이전 셀의 셋째 줄). renderer pagination/engine.rs의 can_intra_split 경로를 그대로 사용한 결과이며 이번 제목 반복 구현에서 행 경계를 재작성하지 않았다. 내용 누락/중복과 제목 반복은 검사했지만 ‘행 사이에서만 나눔’의 모든 조판 조건은 실제 한글 기준과 별도로 검증해야 한다. 이 결과를 완전한 행 경계/한글 지면 동등성으로 표시하지 않는다.
