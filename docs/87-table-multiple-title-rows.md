# 87. 여러 제목 행 지정·반복과 안전한 배치 검사

2026-10-14. 85번의 첫 제목 행 명령을 맨 위부터 연속된 여러 전체 행으로 확장한다. 86번의 보호 셀·표 검사와 기존 사본 preflight·현재 형식 저장 보존 검사는 유지한다. 새 명령을 추가하지 않아 제공자 중립 계약은 45종이다.

```json
{"kind":"set_table_header","target":"s0p1t0","headerRows":2,"repeatHeader":true,"paginationMode":"row"}
```

## 지원 범위

headerRows는 맨 위의 제목 행 수다. 0은 모두 해제, 양의 정수는 해당 개수의 전체 행 지정이다. 200셀 이하의 본문 단순 표에서 현재 표의 행 수 이하로 제한한다. 반복을 켜려면 제목 행이 하나 이상이고 별도 본문 행이 남아 있어야 하며 쪽 나눔을 row로 명시한다. 반복을 끈 제목 표시는 전체 행에도 지정할 수 있다. 제목 수·반복·쪽 나눔은 한 명령/undo로 변경한다. 기존 0/1 요청도 그대로 작동한다.

기존 원본은 제목 표시 없음 또는 맨 위부터 연속된 전체 제목 행 블록만 편집한다. 일부 셀만 제목이거나 중간 행을 건너뛴 제목은 null/읽기 전용으로 표시하고 조용히 줄이지 않는다. 보호/병합/중첩/혼합 서식·필드·캡션·글자 취급/겹침 등 기존 제한도 유지한다. 새 표 alias, 다른 명령과 혼합, 매크로·자동 저장은 이번 명령의 지원 범위가 아니다.

Public DTO의 headerRows를 정수 개수로 확장하고 Domain이 현재 행 수·조합·단독 요청·no-op를 검증한다. Adapter는 현재 실제 표와 지문·제목 수·반복·쪽 나눔을 다시 읽는다. 전체 보존 증거에서 계획한 셀 isHeader와 표 repeatHeader/pageBreak 외에는 변경을 허용하지 않는다. 오래된 문맥이나 제목 원본·보호 값 변경은 거절한다.

## 수동 창과 상태 저장

표 개체 또는 셀 블록을 선택하고 표 메뉴의 ‘제목 행·반복’을 연다. ‘제목 행 지정’과 행 수 입력으로 위쪽 연속 행을 선택한다. 반복을 켜면 제목 지정과 행 단위 쪽 나눔을 함께 선택한다. 제목 지정을 끄면 반복도 끄며 전체 제목 표시를 해제한다. 기존 2행 원본은 창에서도 2로 읽고 수동 설정과 Agent가 동일한 Domain/Adapter를 사용한다.

잘못된 정수/범위·전체 행 반복·변경 없음은 창 안에서 오류로 안내한다. 취소·오래된 문서/표 선택은 변경하지 않는다. 표 개체/본문 셀 블록 선택과 커서를 유지하고 요청/수동 undo·redo, HWP/HWPX 저장·재열기 및 미저장 문서의 업무 복원을 연결한다. 재시작 검사는 미저장 종료 확인창을 테스트에서 명시적으로 승인한 뒤 실제 복구된 내용·제목 수·비교 기록을 검사한다. 확인창을 취소해 재시작이 막힌 테스트와 제품 복구 실패를 구분한다.

## 반복 배치 검사와 엔진 경계

기존 엔진 570603의 model/table.rs leading_header_rows는 맨 위 연속 블록을 계산한다. typeset/table/continuation/fragment/budget.rs는 이미 지나간 제목 행들의 실제 높이와 간격을 이어지는 조각 예산에서 차감하며 layout/table_partial.rs는 같은 블록을 이어지는 쪽에 그린다. 별도의 pagination/engine.rs 분기와 기존 row 정책의 부분 본문 셀 이어짐 관찰은 유지한다. 이번에는 조판/렌더러를 패치하지 않는다.

여러 행 반복을 새로 설정할 때는 Native의 실제 pageCount/getPageControlLayout/getPageInfo도 읽는다. 대상 표가 나타나는 각 조각에 모든 제목 셀이 있고 본문 셀이 남는지, 제목 셀의 유효한 실제 사각형이 쪽 안에 들어오는지 확인한다. 소수 첫째 자리 배치 응답의 반올림 허용은 0.2px이며 좌표를 잘라내거나 출력을 감추지 않는다. 배치를 읽지 못하거나 제목 블록 전체가 들어가지 않으면 preflight가 거절하여 실문서를 바꾸지 않는다. 적용 중 동일 오류가 나면 snapshot router가 요청 전체를 복원한다. 지원 여부의 일반 조회는 후보 판정이며 요청한 제목 수의 실제 배치는 적용 전 사본에서 검증한다.

실제 80행 표에서 60행 제목 반복은 쪽마다 전체 제목과 본문이 함께 들어가지 않아 거절하는 반례를 추가한다. 이를 저장 성공이나 엔진 결함 해결로 표시하지 않는다. 반복을 끈 제목 수 설정과 기존 단일 행 경로는 유지한다. 키 큰 제목·복잡한 조판과 모든 문서의 한글 동등성은 별도다.

자체 30행·60셀 예시에서 2행/3행 제목의 모든 고유 라벨이 각 쪽에 한 번씩 표시되고, 나머지 54개 본문 항목·둘째/셋째 줄이 전체에서 한 번씩 나타나는지 실제 SVG로 검사한다. 반복을 끄면 제목은 첫 쪽에만 남는다. 저장 텍스트는 복제하지 않으며 HWP/HWPX 재열기 후에도 검사한다. 이 합성 예시 검증은 독립 한글 출력 비교를 대신하지 않는다.

## 검수본과 남은 작업

검수본은 `build/jueony-table-multi-header-20261014/Start-Review.cmd`, 주소는 `http://127.0.0.1:4302/`다. 이전 4300/4298 등 실행본과 사용자 문서는 유지한다. 성공 편집 출력과 키 큰 제목의 거절 입력을 구분해 한글에서 확인할 수 있게 준비한다. 네 제공자는 실제 adapter에 합성 프로토콜을 연결하며 유료 모델 호출·한글 2024 직접 비교는 미실행이다.

표 크기/여백/테두리·병합/분할·복합 표, 고급 스타일·개체/필드·검토/서명·문단 restart 안전 저장과 전체 한글 동등성은 아직 미완료다. 전체 범위가 실제 완료될 때까지 자동화를 유지한다.
