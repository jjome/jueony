# 96. Agent 사각형 셀 병합

2026-10-15. 기존 수동 병합 엔진을 새 제공자 중립 명령으로 연결한다. 셀 분할·병합 원본의 재편집은 별도 후속 과제이며 한글 2024 직접 비교는 마지막에 수행한다.

## 계약과 사용

```json
{
  "kind": "merge_table_cells",
  "target": "s0p1t0",
  "startRow": 0,
  "startColumn": 0,
  "rowCount": 1,
  "columnCount": 2
}
```

최신 문서에서 조회한 `tableMergeSources[target].editable:true`와 실제 ID를 사용한다. 행/열 값은 0부터 시작하며 `rowCount/columnCount`는 끝 위치가 아닌 개수다. 최소 두 셀인 사각형을 명령 하나로 요청한다. 중립 wire는 45종에서 46종으로 확장하며 네 제공자 adapter는 공통 계약을 사용한다. SDK 응답이나 Native 인자를 UI/Agent에 노출하지 않는다.

지원 원본은 한 쪽에 모두 표시된 HWPX 본문 평면 표다. 단일 단·문단 왼쪽 배치, 정규 행/열 격자·일치하는 열 너비/행 높이, 200셀 이하를 요구한다. 선택 셀의 크기 외 속성·테두리·배경·안 여백·제목 상태는 같아야 한다. 서로 다른 글자/문단 서식은 각 문단과 함께 보존한다.

좌상단 셀에 행 우선 순서로 문단을 모은다. 내용 없는 보조 셀은 문단을 보태지 않으며 좌상단의 빈 문단은 유지한다. 병합 결과의 저장 너비·높이는 선택 열 너비·행 높이의 정수 합이다. 커서는 결과 셀의 첫 문단으로 옮기고 흡수된 셀 ID를 후속 명령에 재사용하지 않는다. 요청 undo/redo와 미저장 workspace 복원을 지원한다.

HWP, 기존 병합·중첩·보호·혼합 run/복합 셀, 셀 간 속성이 다른 병합은 거절한다. 문서에 필드·책갈피·머리말/꼬리말·개체·중첩 list가 있어 소유 재배치를 완전히 확인할 수 없어도 거절한다. 새 표 생성과 병합의 묶음, 별칭·반복 작업·매크로는 지원하지 않는다. 병합 결과는 여러 문단·span을 가지므로 현재 단순 셀 내용 편집이나 추가 병합의 대상이 되지 않을 수 있다. 사용자 수동 편집과 되돌리기는 기존 기능을 사용한다.

## 문서 소유와 보존

도메인은 detached snapshot에서 대상·범위·크기·속성 호환성을 계산한다. adapter는 Native 원본과 fingerprint, 보호·문서 list 소유를 다시 확인하고 기존 `mergeTableCells`를 호출한다. 엔진을 새로 구현하거나 Rust 패치를 추가하지 않는다.

병합으로 Native list slot ID, 셀 번호·span·문단 수와 평탄 텍스트의 순서가 바뀐다. 이 명령 안에서는 임시 list ID만 제거하고, 명시적으로 계획한 결과 list 주소·셀 수·span·문단 수와 문단/글자 run을 정확히 비교한다. 평탄 문자열 대신 **모든 본문과 모든 표 셀 텍스트**를 계획한 트리로 비교한다. 같은 글자 수의 다른 표 내용 오염도 거절한다. 표 공통 속성·자원·이웃 셀·다른 표·저장된 문단/글자 서식은 그대로여야 한다. 공통 저장 보존 검사 자체를 바꾸거나 허용 오차를 늘리지 않는다.

사전 검수 문서와 열린 실제 문서에서 각각 실행하고 전체 보존 증거와 실제 셀/글줄 배치를 검사한다. HWPX 저장 재열기와 실제 화면 재렌더 후에도 결과를 확인한 뒤 이력을 확정한다. 부분 Native 실패·이웃 오염·렌더/저장 배치 불일치는 요청 전체를 원복한다. 지연 응답 중 사용자 수정은 충돌로 거절한다.
