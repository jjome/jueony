# 98. Agent 기본 병합 셀 분할

2026-10-15. `N003`의 제한된 기본 분할을 실제 열린 문서에 연결했다. 제공자 중립 명령 `split_table_cell`이 47번째 명령이다. 모델에 조회된 표와 원본 병합 셀 주소를 전달하고, 현재 문서·표 구조와 보존 지문을 검증한 뒤 기존 엔진으로 적용한다.

## 지원 범위

- HWPX 한 쪽 본문 평면 표, 최대 200셀, 병합 셀 하나. 다른 셀은 단일 문단과 단순 글자 서식이어야 한다.
- 다른 행·열의 실제 단일 셀에서 너비·높이의 정수 HWPUNIT 증거를 얻는다. 병합 셀의 크기 합과 정확히 맞는 경우에만 원래 격자로 분할한다. 불균등 크기를 그대로 유지한다.
- 병합 셀의 여러 단순 문단과 각 문단·글자 서식은 첫 셀에 모두 남긴다. 새 셀은 비어 있으며 첫 문단의 서식을 이어받는다. 병합 전 셀별 내용을 복구하는 기능이 아니다. 직전 병합의 원복은 되돌리기를 사용한다.
- 셀 목록·주소·크기·문단·글자 속성, 모든 본문과 표의 텍스트, 자원과 인접 표를 검증한다. 적용/되돌리기/다시 실행, 첫 셀 커서, 변경 전후 확인, 저장·재열기와 미저장 세션 복원을 연결했다.
- 요청 생성 중 사용자 변경은 버전 충돌로 거부한다. Native 실패·무변경·예외, 다른 표의 같은 길이 텍스트 오염과 렌더 후 지면 불일치는 기존 트랜잭션으로 원복한다.

전체 병합으로 행·열 크기의 증거가 없어진 표, 추가 병합 셀, 보호·필드·책갈피·중첩·표 제목·반복·쪽 넘김 표, 복합 문단 및 일반 HWP는 거부한다. 임의 N×M 분할, 표 나누기·붙이기와 병합 후 복합 편집은 별도 후속 작업이다. 저장 보호 검사와 0.2px 지면 허용치는 완화하지 않았다.
