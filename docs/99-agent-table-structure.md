# 99. Agent 표 나누기·붙이기

2026-10-15. `N008`을 제한된 원본 범위에서 구현했다. `split_table`과 `attach_table`을 추가해 제공자 중립 편집 명령은 49종이다. 사용자와 AI가 같은 열린 엔진의 문서를 사용하며 별도의 디스크 문서 수정은 하지 않는다.

## 실제 동작

`split_table {target,atRow}`는 조회된 내부 행 경계에서 표를 나눈다. `atRow`는 뒤 표의 첫 행의 0 기반 주소이며 앞 표에 남기는 행 수다. 예를 들어 1이면 첫 행을 앞 표에 남긴다. 커서는 기존 수동 편집처럼 새 뒤 표의 첫 셀로 이동한다.

`attach_table {target,nextTarget}`는 조회된 호환 가능한 다음 표만 앞 표에 붙인다. 사이의 빈 문단과 뒤 표 host를 제거하고 셀과 문단 내용을 순서대로 유지한다. 커서는 합쳐진 앞 표의 첫 셀로 이동한다. 사이에 내용·다른 컨트롤이 있거나 칸 수·너비·표 속성이 다르면 거부한다.

현재 원본 범위는 HWPX 한 쪽·한 단의 비보호 평면 격자, 미병합·단순 문단/글자 서식, 실제 너비·높이와 빈 표 host다. 최대 200셀이다. 표 제목 반복·캡션·겹침·쪽 분할·중첩·필드·책갈피·복합 원본과 일반 HWP 편집은 제외한다. HWP로 내보낸 뒤 보존·재열기 검사는 통과했지만 HWP 원본을 AI로 편집할 수 있다는 의미는 아니다.

대상·인자·버전·전체 보존 지문을 확인한다. 의도된 root 문단/flattened 컨트롤/셀 주소·크기 변환만 허용하고 모든 본문·표 텍스트·문단/글자 서식·자원·앞뒤 구역·다른 표를 비교한다. 단독 요청이며 매크로나 자동 저장에는 등록하지 않았다. 오래된 요청·실패·무변경·다른 내용의 오염·렌더/저장 불일치는 실패로 보고하고 요청 단위로 원복한다.
