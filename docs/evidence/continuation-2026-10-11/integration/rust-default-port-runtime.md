# 기본 포트 런처 검수 제한

기본 4173 포트의 Rust 런처 테스트 실행파일은 컴파일에 성공했지만 Windows 애플리케이션 제어 정책에서 실행을 차단했다. PowerShell의 `StandardOutputEncoding` 오류 뒤 직접 실행에서 정책 차단을 확인했다. 보안 설정 변경이나 우회 실행을 하지 않았다.

4191 포트로 컴파일한 동일 코드의 검수 런처 단위 검사는 3/3 통과했다. 이 결과를 기본 포트 테스트의 실행 성공으로 대체하지 않는다. 제공되는 `Start-Review.cmd` / `Start-Jueony.cmd`는 PowerShell 실행기로 4191에 연결한다. EXE의 사용자 환경별 실행 허용은 별도 확인 대상이다.
