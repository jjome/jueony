# 파일 보존 후속 검수 근거

2026-10-17 중간 검수 묶음이다. **전체 완료 판정이 아니다.**

- `hancom/`: 직접 만든 표/본문 검수 문서를 실제 한글 2024 UI에서 열고 새 사본으로 저장한 쌍이다. 수정 전 c370 엔진의 독립 비교 실패도 `baseline-failures.json`에 그대로 보관한다.
- `engine51/`: 표 후속 흐름과 여러 글줄·읽기 전용 표시 문단의 저장 처리를 수정한 51개 패치 엔진 `5921bb9f9dcd86fa`의 검수다. 엔진 72개와 Edge 14개 시나리오는 각각 전부 통과했다. 서로 겹치는 기능이 있어 기능 수·제품 진행률로 합산하지 않는다.
- `prior-verification-audit.json`: 앞선 검수에서 직접 한글 검증이 남았던 항목이다. 자동 검사 통과가 한글 UI·인쇄 일치를 대신하지 않는다.
- `manifest.json`: 원본 로컬 경로·파일 크기·SHA256이다. 기존 실패를 새 성공으로 덮어쓰지 않는다.

이 엔진은 표와 본문의 세로 흐름 차이를 수정한다. 한글 글자폭·줄 분할 차이, Windows 종료 후 복구 등 후속 작업의 최종 증거는 [109번 문서](../../109-file-preservation-hancom-followup.md)에 따로 기록한다. 선언된 표 높이를 임의로 바꾸거나 저장 보호 검사 허용치를 늘리지 않았다.
