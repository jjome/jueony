# 정식75 저장·손실 보고 검수

엔진75는 음수 위치 표의 물리 원점·흐름 예약을 동일 계약으로 처리하고, HWPX에서 실제 빠지는 Unknown 컨트롤을 정확한 소유 경로로 손실 보고한다. 저장 전 보호 검사를 완화하지 않았다.

기존 회귀44개(Native27·실제 Edge17) 모두 통과했다. 실제 한글11쌍 전체 의미·지면 비교는10통과이며 두 단 문서37차이는 남아 있다. 음수 위치 원본·한글 사본 양형식 연속 저장·재열기가 통과했다. 이전 실패와 별도 Native 검수를 같은 통과 수로 합산하지 않는다.

unknown-wasm은 실제 파싱되는 자체 HWP 두 개를 읽는다. 정상 표는 엄격 저장을 통과하고, 4cc 네 바이트를 바꿔 Unknown이 된 자체 파일은 정확한 손실 한 건과 생산 PreservationError를 반환한다. 원본 모델·HWP 내보내기 바이트·편집 이벤트·디스크 입력은 불변이다. OS 저장창을 실행했다는 뜻은 아니다.

negative-native 및 unknown-native는 독립 Rust 후보·baseline·실패 이력의 원본을 복사한 것이다. 각 original-manifest.json의 경로는 원래 묶음 기준이다. 큰 JSON만 원본 바이트 그대로 gzip으로 압축했으며 summary.json의 원본 지문으로 검증할 수 있다. 일부 옛 검수기가 잘못된 codec 기준 바이트를 비교한 실패도 그대로 보존했다.
