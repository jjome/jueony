# 최종 합본 전 후보와 실패 근거

여기는 각 독립 수정안과 검수기의 원본 근거다. 최종 합본의 성공 기록으로 대신 사용하지 않는다. mcst-v5는 본문 물리 간격 경계, caption은 번호·부분 속성 수명, transpose는 바뀐 행 측정 소유, gate-tab은 전체 지면 저장 보호와 탭 간격, browser-fault-order는 오염 주입과 원복 검수 순서를 다룬다.

서로 다른 기준 버전과 Native/Node-WASM/실제 Edge 검수는 각 하위 manifest와 설명에서 구별한다. 초기 실패·잘못 준비한 하니스·반증된 후보는 보존했다. gate가 손상 저장을 차단한 성공은 무손실 변환 구현 성공이 아니다. 정식76 MCST 사본은15쪽에서 HWP 변환188차이, 정식77은 원래16쪽을 복구한 상태에서 HWP 변환15쪽/22,186차이로 각각 다른 기준이다.

공개 문서 원본·전체 공개문서 snapshot·폰트·WASM·EXE는 이 묶음에 넣지 않는다. 자체 문서와 숫자/소스 지문으로만 재현 경계를 설명한다. 최종 합본 결과와 남은 제한은 상위 통합 문서에서 별도로 판정한다.
