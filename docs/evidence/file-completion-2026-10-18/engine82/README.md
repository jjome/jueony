# 파일 저장 합본82 검수 이력

이 합본은 파일 기능 전체 완료 선언이 아니다. 원본·실패 보고서를 새 성공으로 덮어쓰지 않는다.

| 검사 | 실제 결과 | 범위 |
| --- | --- | --- |
| 기존 회귀 | 직접WASM27·실제 Edge17 통과 | 실제 Windows 파일 대화상자와 구분 |
| 단위·정적 검사 | 930/930, skip0·타입·모듈 경계 통과 | 같은 합본 소스 |
| 필수 저장 검사 | 폰트3·MCST15·전체 배치7 통과 | actual16쪽, 양형식2회·교대6단계·106 strict 재열기 |
| 실제 한글 재저장 | **FAIL** 의미165·배치5843 | 직접 왕복 성공과 구분; 후속 각주 wire/작성자 누락 조사 |
| 공개 코퍼스 | 별도 실패·자원 감사 보존 | 자체11쌍과 공개 Python/MCST는 다른 입력 |

`regression-reports.json`이 gzip 원문의 경로·SHA를 연결한다. `mandatory-actual-storage`와
`candidates/xml-cache`는 독립 후보/공식 검수를 구분한다. 이전 합본81 증거도 유지한다.
공개 원문·파생 문서·전체 공개 snapshot·폰트 프로그램·WASM·실행파일은 포함하지 않는다.
원시 ID·run 경계의 actual Hancom 변화는 완전 지면 comparator에서 무시하지 않았다.
