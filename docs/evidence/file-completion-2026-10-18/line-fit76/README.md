# 한글 2024 줄 수용 차이의 자체 재현

공개 문서 본문을 재배포하지 않고 같은 글꼴 advance 구성의 자체 문서를 사용했다. 실제 한글에서 로컬 사본으로 저장하고, LEFT 사본은 탭을 닫아 디스크에서 다시 열었다. LEFT와 JUSTIFY 모두 한글 사본의 첫 줄은31자이고, 정식76에서 새로 조판한 자체 입력은30자다. 의미 차이는0, 공개 지면 차이는 각각10/38로 그대로 남긴다.

따라서 JUSTIFY 전용 공백 압축이 원인이라는 가설은 반증됐다. 엔진이 이미 저장된31자 줄을 그릴 때 적용하는 간격 조정은 한글의 새 줄 수용 규칙을 증명하지 않는다. 설치된 굴림체의 hmtx를 읽기 전용으로 측정했지만 5~8HU 차이의 원인은 미확정이다. 수치·비교 허용치·생산 코드를 바꾸지 않았다.

폰트·공개 원문·WASM·EXE는 포함하지 않는다. 자체 HWPX 네 파일, 실제 저장/재열기 캡처, 원시 XML·전체 공개 지면 readback, 준비 오류와 이름 정정을 포함한다. manifest-sha256.json은 전달된 원래29개 payload의 지문이다. SHA256-MANIFEST.json은 이 설명을 포함한 보관본 전체를 봉인한다. 두 manifest를 검수 성공 수로 중복 집계하지 않는다.
