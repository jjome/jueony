# 추후 한글 2024에서 열어볼 저장 파일

원본은 SHA로 고정한 자체 시험 HWP6개다. 각 파일의 첫 본문 문단에 줄바꿈 길이(`wrap`) 또는 여러 쪽 길이(`page`)의 실제 텍스트를 추가한 다음 HWP와 HWPX로 저장했다. 6×2×2=24개이며 바이트 지문은 [index.json](index.json)에 있다.

| 파일 이름의 앞부분 | 시험 목적 |
| --- | --- |
| single_column | 단일 단 |
| three_columns | 세 단과 단 시작 예약 높이 |
| rtl | 오른쪽부터 배치하는 단 순서; 문단 textDir 변환 아님 |
| distribute | 분배 단 배치 |
| unequal_columns | 서로 다른 단 너비 |
| asymmetric_margin | 비대칭 쪽 여백 |

자동 검사에서는 최종 공식 엔진으로 실제 저장·반복 재열기·후속 편집·반대 형식 재저장·Undo/Redo를 확인했다. 실제 한글 검수는 아직 하지 않았다. 같은 폰트 환경에서 HWP/HWPX 한 쌍을 열어 페이지 수, 본문 누락, 표 위치, 셀 줄바꿈을 확인하고 새 이름으로 저장한 결과를 비교할 예정이다. 원본 시험 파일과 사용자 파일을 덮어쓰지 않는다.

이 자료는 최초 조판/글꼴·표현 불명 복합 프레임 등 모든 호환성을 보장하는 표본이 아니다. 현재 결과와 남은 항목은 [상위 증거 설명](../README.md)에 기록했다.
