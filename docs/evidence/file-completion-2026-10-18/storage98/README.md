새4건: 비정상 배열 속성의 일반 읽기 거절, 읽은 뒤 같은 JSON의 비정상 속성이 추가되는 실제 경쟁 쓰기 거절, 정상 동시 변경의 CAS 거절, `-0/0`의 실제 저장값 구별. 새 독립 하니스의 수정 전3건 중1건 실패와 수정 후4건 통과를 before/after에 남겼다. 328에는20과12가 포함된다. 별도 단위를 더해 제품 검증률을 만들지 않는다.

수정은 저장 트랜잭션에서 JSON 바깥의 배열 own key·값까지 비교하는 것이다. scope/원본/이력/용량 제한과 원자적 트랜잭션 보호를 유지한다. 비교 한도는 기존24개×문단별200,000노드와깊이50을 수용하는 총5,000,000노드/깊이64다. 손상된 동시 기록을 자동 복구·덮어쓰기하지 않는다.

Windows Rust 저장10·기존 단표24·독립 OLE날짜28·저장 샘플24는 같은 엔진의96 근거를 재사용하며 이번에 재실행했다고 표현하지 않는다. 새 한글 GUI 검수·실제 외부 LLM 호출·사용자 문서/자격정보 접근은 없다. 파트 전체의 남은 조판·형식/화면 범위가 완료됐다는 뜻이 아니다.
