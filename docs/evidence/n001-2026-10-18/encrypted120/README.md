# N001: 재조판 문서 암호화 저장

범위는 N001의 암호화 행 배치 보존 결함이다. 다른 미완 기능을 포함하지 않는다.

- 공식120 Rust/WASM의 실제7검사 PASS. 같은 검수기의119실행은0/7이며, 기존 제한으로 사전조건부터 실패한 경우도 포함하므로7개의독립제품결함이라고 세지 않는다.
- 실제 앱3검사 PASS: 암호 입력으로 연 자체 문서의 HWP/HWPX SaveAs, 각형식 후속Save, Undo/Redo, 암호변경, 재열기, 후속편집. 실제OPFS기록+Node파일쓰기/재읽기, 원래입력보존, 예기치않은page/console/network오류0.
- 앱 소스는8509733e의 Git archive이며UI소스변경0. 중단된 저장시각·최근문서 기능의 작업트리 변경은 포함하지 않았다. 패치8개의 저장소LF/기존빌드CRLF 차이는 의미동일성을 확인한 후 원래 엔진manifest의 정확바이트로 맞췄다. 보호검사를 건너뛰지 않았다.
- 원본 모델을 바꾸지 않고 현재 유효한 배치기록만 기존 암호 알고리즘으로 암호화한다. 잘못된 암호·손상기록은 새 배치권한을 얻지 못한다. 오래된resource를허용하지 않는다.
- Native개인사본의20회저장·12회복합왕복·4회이력출력과보호반례는별도작성자증거다. 실제WASM7/앱3과합산해하나의실행으로표시하지 않는다.
- N001전체완료는아니다. 구버전저장본의38바이트표기록지원과변환시비해석기록보존을이어수정한다. 한글직접비교는사용자요청에따라보류한다.

`python verify.py`로 봉인 결과의 바이트 지문을 검증한다. Python은 검수 도구이며 수정한 문서 처리 코드는 Rust다.
