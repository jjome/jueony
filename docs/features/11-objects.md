## 진행 요약

실행 작업 **1개**, 상위 범위 **18개**. CSV의 기록을 기능별로 표시한 문서다.

| 구분 | 실행 작업 | 상위 범위 |
| --- | --- | --- |
| 구현 | 완료 ![1/1 완료](<../progress-badges/complete-1-of-1.svg>) · 부분 0 | 완료 0/18 · 부분 11 · 미구현 7 |
| 검증 | 완료 0/1 · 부분 1 | 완료 0/18 · 부분 2 · 미검증 16 |
| Agent 연결 | 해당 없음 1 | 연결 0/18 · 부분 0 · 미연결 18 |

☑ 완료/연결 · ◐ 부분 · ☐ 대기 · ? 재점검 · — 해당 없음. 검증 완료에는 필요한 한글 직접 비교도 포함한다. 구현 완료만으로 세 축 완료가 되지 않는다.

상위 범위는 세 축 완료 **0/18개**다. 세부 작업 완료 수와 분리해서 읽는다.
