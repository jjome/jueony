‘상위 완료’는 필요한 구현·검증·Agent 연결을 모두 충족한 상위 범위 수다. 나머지 숫자는 **완료·연결 / 해당 세부 실행 작업 수**다. ‘상위’는 상세 작업이 아직 없는 영역의 상위 범위 집계다. 다른 행의 세부 작업 수와 합산하지 않는다. 전체 기능 완성률이 아니며, 한글 직접 비교와 미검증 변경은 완료에 포함하지 않는다.

문서 구성일: 2026-10-16. 진행 상태는 검수한 [CSV](jueony-work-checklist.csv)의 기록을 사용한다. 상태를 바꿀 때 CSV를 수정하고 문서를 다시 생성한다.

## 현재 집계

전체 **16개 기능 문서 · 440개 항목**이다. 집계 대상은 **실행 작업 219개**이며, 상위 기능·상태 범위 221개는 중복 분모에 넣지 않는다.

| 구분 | 완료·연결 | 부분 | 남은 작업 |
| --- | ---: | ---: | --- |
| 구현 | 167 | 30 | 미구현 17 · 재점검 5 |
| 검증 | 52 | 130 | 미검증 37 |
| Agent 연결 | 88 | 8 | 미연결 21 · 해당 없음 102 |

세 축과 필요한 한글 검증을 모두 충족한 실행 작업: **52개**.

완료 표시는 각 항목의 제한된 범위에 적용한다. 자동 검사 통과와 한글 2024 직접 비교는 구분한다. 이 수치는 한글 전체 완성률이 아니다. 한글 2024 직접 비교는 마지막 일괄 검수로 진행한다.

## 기록을 갱신하는 방법

1. 해당 기능 문서에서 항목 ID와 완료조건을 확인한다.
2. CSV의 구현·검증·Agent 연결과 자동/한글 검증, 근거·다음 작업을 수정한다.
   통합 중 메모는 기능 분류 원본의 `working`에서 관리하고, 완료 기록 반영 시 정리한다.
3. `python scripts/render_work_checklist.py`로 종합·기능별·전체 문서를 함께 생성한다.
4. `python scripts/render_work_checklist.py --check`로 ID 누락·중복 분류·근거·집계·생성 파일 일치를 확인한다.
