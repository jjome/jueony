## 다음 우선 작업

각 영역의 명시적인 후속 작업을 먼저 표시한다. 연결을 누르면 해당 항목의 범위·실제 상태·근거로 이동한다.

- **업무·채팅·폴더 관리**: 검증 — [G005](<features/01-workspaces.md#g005>) 업무 생성·전환·이름 변경

- **참고 자료·검색·RAG**: 구현 — [N033](<features/03-references-and-rag.md#n033>) 검색 순위·구본 우선 문제와 무답 판별
- **반복 작업·공무원 업무 양식**: 구현 — [N038](<features/04-macros-and-business.md#n038>) 반복 작업의 표·개체 명령 확장
- **파일·저장·복구·형식 보존**: 구현 — [N001](<features/05-files-storage-recovery.md#n001>) HWP 겹침 허용 후속 표의 화면/재열기 위치
- **본문 편집·입력·선택·찾기**: 검증 — [A001](<features/06-editing-and-selection.md#a001>) 새 본문 문서 작성
- **글자·문단·스타일·번호**: 구현 — [N011](<features/07-formatting-and-styles.md#n011>) 스타일 가져오기·내보내기

## 통합 검증 중인 변경

아래는 현재 작업 중인 후속 묶음이다. 최종 검증과 기록 갱신 전에는 위 완료 수치에 추가하지 않는다.

- [파일·저장·복구·형식 보존](<features/05-files-storage-recovery.md>): HWP 후속 본문 표 저장 보정과 관련 실제 브라우저 검사를 통합 중이다. 현재 CSV 완료 상태에는 추가 반영하지 않았다.
- [표·셀·크기·계산](<features/08-tables.md>): 병합 표 행 높이의 Native 수정과 속성 대화상자의 변경 값 보존을 검증 중이다. 병합 행열 Agent 전체 연결은 완료로 표시하지 않는다.
- [상태 저장·환경·선택 복원](<features/13-state-and-preferences.md>): 머리말·각주 story의 서식·소유·문맥 지문을 강화하는 후속 코드를 통합 검증 중이다. 기존 완료 기록과 새 미검증 변경을 구분한다.

## 기록을 갱신하는 방법

1. 해당 기능 문서에서 항목 ID와 완료조건을 확인한다.
2. CSV의 구현·검증·Agent 연결과 자동/한글 검증, 근거·다음 작업을 수정한다.
   통합 중 메모는 기능 분류 원본의 `working`에서 관리하고, 완료 기록 반영 시 정리한다.
3. `python scripts/render_work_checklist.py`로 종합·기능별·전체 문서를 함께 생성한다.
4. `python scripts/render_work_checklist.py --check`로 ID 누락·중복 분류·근거·집계·생성 파일 일치를 확인한다.
