### N004 중단 지점과 재개 조건

1. 10pt 원본에서 앞 글을 추가해 1→2줄로 바꾸는 검사는 **실패**했다. 보호 검사를 통과하지 못하므로 지원 완료로 표시하지 않는다.
2. Rust TextRun 문자 위치 수정만 포함한 엔진 `23bb836678d1c64e`는 빌드·패키지 기본 검사를 통과했다. 이후 10pt 검수에서 줄 끝 커서가 앞줄 그림을 선택하는 별도 오류가 남아 있음이 확인됐다.
3. 같은 패치에 줄 끝 탐색의 그림 위치를 실제 원문 문자 위치로 맞추는 후속 수정안이 작성돼 있다. **후속 수정안의 재빌드·저장 재열기·Edge 검수는 아직 미실행**이다.
4. 가운데 정렬 재조판의 세로 이동 증명도 로컬 수정안에 있다. 리뷰에서 **새로 생긴 줄의 가로 시작 위치를 독립적으로 검사하지 않는 빈틈**을 발견했다. 실제 재현 전의 정적 리뷰 지적이며 보완 후 음성 검사가 필요하다.
5. 다음 재개 시 가로 위치 검증 보강 → 후속 Rust 패치 빌드 → 10pt HWP/HWPX 선별 검사 → 실제 두 줄 상태의 앱 저장·UI 재열기 순으로 진행한다. 통과한 N005·N007의 전체 검사는 관련 코드 변경이 없다면 반복하지 않는다.

## 앞선 검수 기록

기존 사용자 작업을 제외한 체크아웃에서 Rust 엔진 `6f1d84832c1fc875`를 포함해 편집기를 빌드했다. Edge에서는 합성 문서와 로컬 모의 제공자를 사용했다. 병합 문단 6건, 중첩 문단 4건, 격자 편집 2건, 중첩 계산식 2건에서 실제 요청, 되돌리기·다시 실행과 파일 재열기를 검사했다. 한글 2024 직접 비교는 남아 있다.

후속 검수에서는 앱 `8356d3c0`과 Rust 엔진 `f5f556a7c1b8eaa8`에서 중첩 표 행 삽입·열 삭제 4건, 계산식이 있는 병합 표의 행 삽입 2건, 다쪽 셀 분할과 거부 4건, 누름틀 두 개가 있는 병합 셀의 본문 교체 2건을 Edge로 확인했다. 계산식 필드는 저장 파일을 별도 판독기로 읽어 이동한 참조와 표시값 `12.00`·`24`를 대조했다. 중첩 표 단위 검수는 행과 열의 삽입·삭제 네 방향을 모두 포함한다.

행·열을 삭제할 때 그 안의 계산식을 함께 삭제하는 경우도 검사했다. 해당 셀을 참조하는 수식이 남아 있으면 거부한다. HWP·HWPX에서 수식이 1개 또는 0개 남는 저장 파일 8개를 독립 판독기와 엔진으로 다시 읽었다. 두 형식에서 기존 수식 보존과 삭제를 포함한 집중 검사 10건이 통과했다.

계산식과 관계없는 병합 셀 문단은 같은 본문 표나 이웃 표에 계산식이 있어도 편집할 수 있다. 편집 가능한 셀 목록에서 계산식 셀과 그 입력 셀을 제외한다. 두 형식의 Edge 검수에서 독립적인 문단만 수정하고, 실행 취소·다시 실행과 저장 후 양쪽 표의 계산식 명령·표시값·위치를 확인했다.

다쪽 셀에서는 화면의 글꼴 측정값을 검사용 사본과 재열기 사본에 등록한다. Edge에서 이모지의 글자 폭이 화면과 사본에서 각각 18.3px와 6.7px로 달랐던 사례를 재현하고, 같은 측정 조건에서 페이지별 셀·글줄 좌표가 일치하는지 확인했다. 양 형식에서 이모지를 포함한 셀 분할과 저장 재열기가 통과했다. 글줄이 실제로 다음 쪽으로 밀리는 문서는 원복을 확인했다.

행 삭제 시 열 너비를 개별적으로 기록한 마지막 행이 사라지면, 엔진이 21000이던 표 너비를 12600으로 줄이는 결함이 있었다. 삭제 전 치수와 삭제 직후 엔진이 계산한 대체값을 모두 확인할 수 있을 때 원래 전체 너비를 복원한다. 실제 HWP 레코드와 HWPX XML에서 너비 21000과 높이 4000을 확인했고, 남은 셀의 너비 12000·9000과 글자 서식이 유지됐다. 삽입 시에도 새 셀의 너비와 높이를 원본 격자에서 확정할 수 있어야 한다. 원본에 없는 개별 너비를 관례적인 기본값으로 채우는 동작은 차단한다.

### 양식 문서의 표 편집

| --- | --- | --- |
| 병합 셀 문단 교체 | 같은 문서의 다른 본문 표에 누름틀이 있어도 선택한 셀의 누름틀 뒤를 수정한다. | 두 표의 셀·문단 번호가 같아도 표별 경계를 사용한다. 저장 후 원래 필드 ID·입력값·안내 상태를 대조한다. |
| 병합 셀 분할 | 이웃 셀에 누름틀·이름 필드가 있는 양식 표에서 일반 문단을 담은 병합 셀을 원래 두 칸으로 복원하거나 세 칸으로 새로 분할한다. | 분할 후 이동하는 이웃 셀의 주소와 가상 필드 ID를 계산한다. 저장 후 누름틀 ID·이름·원문·안내문과 이웃 글줄 위치를 대조한다. 필드를 소유한 셀의 분할은 거부한다. |
