# 표·셀·크기·계산 검수

| 작업 | 구현한 동작 | 확인한 범위와 남은 항목 |
| --- | --- | --- |
| N004 병합 셀 문단 | 여러 쪽에 걸친 셀의 원문을 조각별로 대조한다. 기존 누름틀 뒤의 문장을 바꾸고, 결과의 지정 구간에 굵게·기울임·색·글자 크기를 적용할 수 있다. | HWP·HWPX에서 원래 글자 모양 정의와 자원을 대조하고 되돌리기·다시 실행·재열기를 확인했다. 임의 개체나 다른 필드가 들어 있는 문단은 부분 지원이다. |
| N005 N×M 분할 | 여러 병합 셀이 있는 표에 새 격자선을 추가하고 서식 있는 문단을 나눠 담는다. 여러 쪽 표에서는 원본 행·열로 셀을 찾는다. | 둘째 쪽의 병합 셀을 세 칸으로 나눠 HWPX로 재열었다. 이 검수에서 대상 셀 자체는 한 쪽에 있다. 중첩 표와 대상 셀이 쪽 경계를 지나는 경우가 남았다. |
| N006 중첩 표 | 같은 내용의 표가 여럿이어도 부모 경로와 셀·문단 위치를 지정해 한 곳만 수정한다. 병합된 주 셀과 여러 글자 서식에 걸친 문단도 지정할 수 있다. | HWP·HWPX에서 이웃 표, 보호된 상위 셀, 저장 후 글자 서식을 확인했다. 중첩 표 구조 변경은 별도 작업이다. |
| N007 병합 행·열 | 이웃 셀의 너비와 높이가 결정하는 격자선을 복원한다. 행·열 추가·삭제 후 살아남는 이름 셀과 누름틀의 경로·명령·내용을 대조한다. | 크기를 하나로 결정할 수 없거나 필드 소유 셀이 삭제되면 중단한다. 계산식 보유 표와 중첩 구조는 이 검수 범위 밖이다. |
| N009 계산식 | 본문·중첩 표의 계산식 필드를 만들고 수정한다. 병합 셀의 가려진 좌표를 참조할 수 있고, 집계 범위 안에서 같은 셀은 한 번 계산한다. 원본 숫자 수정 시 연관 필드 결과도 갱신한다. | 편집기에 제공하는 함수, 순환·정의역 오류, 상위 셀 보호를 검사했다. HWP 레코드와 HWPX XML에서 명령과 표시값을 대조했다. 편집 범위는 200칸 이하, 중첩 8단계 이하, 셀 전체를 차지하는 단일 문단 계산식이다. |
| N010 자동 채우기 | 병합·중첩 셀에 날짜·번호·수식·고정 계산값을 채운다. 상대·절대 참조와 날짜 표기를 유지하고 괄호 안 한글 요일을 계산한다. 여러 행이 한 셀을 공유하면 같은 결과가 나와야 한다. | 두 형식의 저장·재열기, 실제 중첩 필드 복사, 같은 셀에 대한 충돌 거절 및 원복을 확인했다. 병합 셀 일부만 선택한 쓰기는 거절한다. |

## 검증 방법

기존 사용자 작업을 제외한 체크아웃에서 Rust 엔진 `6f1d84832c1fc875`를 포함해 편집기를 빌드했다. Edge에서는 합성 문서와 로컬 모의 제공자를 사용했다. 병합 문단 6건, 중첩 문단 4건, 격자 편집 2건, 중첩 계산식 2건에서 실제 요청, 되돌리기·다시 실행과 파일 재열기를 검사했다. 한글 2024 직접 비교는 남아 있다.
