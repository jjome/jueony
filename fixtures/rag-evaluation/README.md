# 자료 검색 시험 예제

가상기관의 합성 업무 자료 21개와 평가 질문 22개다. 실제 기관 문서나 행정 규정이 아니다. HWP 5개, HWPX 5개, MD 7개, TXT 4개를 포함한다. 동일 내용의 HWP/HWPX 쌍은 형식 비교용이며 일반 질문에는 `manifest.json`의 `primaryFile` 하나를 사용한다.

평가 업무 A에 `workspace-service`와 `shared`를 연결한다. 업무 B에는 `workspace-other`를 연결한다. `temporary` 파일은 필요한 채팅에만 임시 첨부한다. 폴더 연결만으로 자료가 자동 분석되지는 않으며 요청에 참고할 파일을 직접 지정한다.

`manifest.json`과 `evaluation-cases.json`, 이 README는 모델의 참고 자료에 넣지 않는다. 예제 루트 전체를 참고 선택하지 말고 네 입력 폴더의 필요한 파일만 선택한다. 두 JSON은 버전·해시·정답과 평가 메타데이터다. 전체 자료는 요청당 20개 한도를 넘는다.

예를 들어 `service-budget-2026-v2.hwpx`와 `service-budget-2026-v1.txt`를 선택하고 “2026년 10월 현재 민원 문서 전환 사업의 확정 총예산은 얼마인가요? 근거 파일과 단위를 알려 주세요.”라고 요청한다. 정답은 2차 현재 예산 48,000,000원이고, 1차 구버전 36,000,000원과 구분해야 한다.

자세한 사용법과 측정 한계는 저장소의 `docs/45-rag-evaluation-corpus.md`, 실행 묶음의 `45-rag-evaluation-corpus.md`를 따른다. 현재 검색은 문자열 기반이다. 임베딩 검색·모델 답변 정확성·실제 한글 지면 호환성을 확인한 자료가 아니다. 기존 저장소 LICENSE.txt 조건을 따른다.
